[1. 홍보 세트 가져오기 — PNG 를 하나씩 넣을 필요 없음]
1) emoti-promo-backup-mongi-day.zip 을 휴대폰으로 옮긴다
   (예: 구글 드라이브에 올린 뒤 휴대폰에서 내려받기, 또는 카카오톡 '나와의 채팅'으로 보내고 저장).
2) emoti 이모티 앱 → 홈 오른쪽 위 '설정' → '백업에서 되살리기' → 그 ZIP 파일을 고른다.
3) "몽이의 하루 세트를 되살렸어요(그림 28개)" 알림이 뜨면 끝.

  들어오는 내용: 세트 '몽이의 하루' · 32칸 중 1~12칸 완성 표시(나머지 20칸은 비어 있음)
    01 안녕   몸·손 두 레이어 + 부분 움직임(손만 회전, PRO)
    02 신나   통통(세기 0.7 · 속도 0.5)
    11 삐짐   흔들기(세기 0.7 · 속도 0.5)
    그 밖의 칸 고마워·미안해·좋아·축하해·졸려·울먹·놀람·응원·잘 자 (움직임 없음)

  기존 작품은 덮어쓰지 않는다(앱과 같은 복원 코드로 PC 에서 확인):
    - 그림은 모두 새 이름으로 저장 — 이미 있는 그림 파일 내용이 바뀌지 않음
    - 새 세트로 추가 — 이미 '몽이의 하루'가 있거나 두 번 가져오면 '몽이의 하루 (복원)' 사본으로 들어옴
    - 아직 실제 휴대폰에서 가져오기를 해 보지는 않았다(이번 환경에 연결된 기기·에뮬레이터 없음).
  다 찍은 뒤 지우고 싶으면: 홈의 세트 목록에서 '몽이의 하루' 옆 관리(⋯) → '세트 삭제'(휴지통, 30일 안 되살리기 가능).

[2. 캡처 동선 — 휴대폰 자체 화면 캡처(전원+볼륨 아래)로 4장]
  ① phone-1.png  홈 → 몽이의 하루 → 02칸(신나) → 위 '움직이기' 탭 → 아래 묶음에서 '동작'
                 확인: '통통' 카드가 선택됨 · 위에 세기 '세게' / 속도 '보통' 막대가 보임
  ② phone-2.png  뒤로 → 10칸(응원) → '그리기' 탭 그대로
                 확인: 캔버스에 응원 그림 · 아래 펜/연필/마커 줄이 보임
  ③ phone-3.png  뒤로 → 01칸(안녕) → '움직이기' 탭 → '부분만 움직이기'
                 확인: '손 · 회전' 줄이 켜짐 · 아래 '+ 몸' '+ 손'
                 ※ PRO 기능 화면이다. 지금 설치된 검토용 앱이면 설정의 '검수용 PRO'가 켜져 있어야 한다
                   (검수용 스위치는 검토용 빌드에만 있고 출시본에는 없다).
  ④ phone-4.png  뒤로 → 보드(세트 화면) 맨 위
                 확인: '12개 완성 / 32칸' · 01~12칸에 서로 다른 몽이 12표정

  캡처 4장을 PC 의 한 폴더에 phone-1.png ~ phone-4.png 로 넣어 주면,
  같은 구성으로 앱 화면 칸만 실제 캡처로 바꾸고 DRAFT 표시를 뗀다:
    node scripts/promo/compose.cjs <나갈 폴더> --ui verification/promo/ui-v2 --device <캡처 폴더>
  (캡처가 없는 번호는 계속 대체 렌더 + DRAFT 로 남는다)

  · 통통: 엔진 값이 좌우 이동 0 → 같은 세로축에 '눌린 잔상 + 뜬 순간 + 그림자'로 표현.
  · 부분 움직임: 손 레이어만 −30°/0°/+30°, 몸은 그대로.
