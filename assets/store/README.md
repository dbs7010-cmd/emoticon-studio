# assets/store — Play 스토어 등록 그래픽 (앱 빌드에 들어가지 않음)

| 파일 | 규격 (Google Play) |
|---|---|
| play-icon-512.png | 512×512, 32-bit PNG(알파 가능), 1024KB 이하 |
| feature-graphic.png 또는 .jpg | 1024×500, JPEG 또는 24-bit PNG(알파 없음) |
| screenshots/phone-01.png … phone-08.png | 2~8장, JPEG 또는 24-bit PNG(알파 없음), 변 320~3840px, 긴 변 ≤ 짧은 변×2, 권장 세로 1080×1920 이상 |

스크린샷은 **실기기에서 출시 후보 빌드를 캡처**한다. 그림·목업을 넣지 않는다. 검사: `npm run assets:check`.
