#### 개인 휴대폰은 쓰지 않는다 (2026-09-12 확정)
사용자는 **개인 휴대폰 사용을 허가하지 않았다.** 다음을 하지 않는다:
- USB 디버깅·무선 디버깅·페어링 요청

#### 네이티브 빌드는 ASCII 경로에서만 된다 (이 PC의 함정)
사용자 폴더 이름이 한글(`C:\Users\민건`)이라, Android Gradle Plugin이 만드는 `prefab_command.bat` 안에서
그 경로가 `誘쇨굔` 로 깨진다. 배치 파일은 UTF-8로 쓰이는데 cmd 는 CP949로 읽기 때문이다. 그러면
"지정된 경로를 찾을 수 없습니다"에 이어 `^` 줄 연결까지 어긋나 `'gle.prefab.cli.AppKt'` 같은 엉뚱한 오류가 난다.
빌드에 쓰는 경로를 전부 ASCII로 돌려서 푼다(관리자 권한 불필요):

| 무엇 | 값 | 방법 |
|---|---|---|
| SDK | `C:\Android\Sdk` | **폴더를 실제로 옮긴다.** 정션(`mklink /J`)은 안 된다 — Gradle 이 경로를 정규화해 한글 원본으로 되돌아간다 |
| Gradle home | `C:\gradle-home` | `GRADLE_USER_HOME` |
| 임시 폴더 | `C:\build-temp` | `TEMP`, `TMP` |
| JDK | Unity 번들 OpenJDK 17 | `JAVA_HOME` (공백은 있어도 되고 한글만 없으면 된다) |

`android/local.properties` 의 `sdk.dir` 도 `C:\Android\Sdk` 를 가리켜야 한다.

경로를 고친 뒤에는 **이미 만들어진 CMake 작업 폴더를 지워야 한다.** 옛 경로가 ninja 파일 안에 박혀 있어
`buildCMakeDebug` 가 계속 한글 경로를 부른다. 지울 곳:
`node_modules/*/android/build/intermediates/cxx`, `**/.cxx`.
빌드 순서: prefab → CMake → dex. prefab 에서 막히면 경로 문제, CMake 에서 막히면 캐시 문제다.

### 제품 범위
- **무료**: 그리기 도구 일습(펜·붓·연필, 굵기, **진하기, 선 보정 약·중·강, 스포이드, 내 팔레트, RGB·투명도** — 38차에 무료로 전환) +
  전체 움직임 3종(통통·흔들기·두근거리기) + 속도·세기 + 보관한 움직임 +
  워터마크 없는 정상 해상도·투명 배경 파일 묶음 내보내기. 저장·출력 횟수 제한, 강제 광고, 상용 이용권 별도 결제 없음.
- **PRO**(38차 재정의 — 기본 도구 잠금이 아니라 생산성·고급 표현): 부분만 움직이기(회전·이동·크기), 여러 부분 독립 적용, 함께/차례로, 두 모습 번갈아,
  **여러 칸에 같은 움직임 한 번에(일괄 적용)**, 고급 브러시 4종. PRO 는 **시작 전에** 알린다(만든 뒤 저장할 때 막지 않는다). 설계 `docs/UX_RESET_BLUEPRINT.md`.
  월간·연간 동일 기능. 제안가 월 4,900원 / 연 39,000원 — **등록·승인된 가격이 아니며 결제 화면은 스토어 가격을 쓴다.**
- 승인·판매 수익을 보장하는 문구는 쓰지 않는다.

### 저장 구조 — 전부 선택 필드
`Slot.motion`(움직임 설정) · `Slot.motionImage`(내보낼 GIF) · `Store.entitlement`(이용권).
구형 정지 프로젝트는 이 셋이 없을 뿐이고 그대로 열린다. 기존 필드는 의미를 바꾸지 않았다.
움직임은 그림과 분리되어 있어 **그림을 고쳐도 움직임이 남고, 움직임을 빼면 원래 정지 컷이 그대로 남는다.**

### 움직임 계약
- 한 컷의 모든 움직임은 하나의 루프 길이 안에서 정수 배 주기로 돈다 → **반복 경계에 이음새가 없다.**
- 미리보기와 파일 출력이 같은 `buildLoop()`를 쓴다 → 보이는 것과 나가는 것이 같다.
- 움직임이 화면 밖으로 나가면 `clipped`로 알리고 세기를 줄이도록 안내한다(임의 보정 없음).
- 문구는 기본적으로 움직이지 않는다.
- 인코딩은 기기 안에서 끝난다(의존성 없는 GIF89a 작성기).

### PRO 권한
- 앱 안의 어떤 토글로도 PRO가 열리지 않는다. `source: 'store'` 영수증만 권한을 만든다.
  이 빌드에는 결제 모듈이 없어 `purchase()`는 **성공을 흉내 내지 않고 unavailable을 돌려준다.**
- 만료돼도 작품과 파일은 삭제되지 않고, **이미 저장한 PRO 효과는 계속 재생·재출력된다.**
  새로 만들거나 바꾼 PRO 효과만 권한을 요구한다.
- 오프라인에서 기존 유효 권한을 제거하지 않는다.

### 제출 규격
`KAKAO_STATIC_SPEC`(정지) / `KAKAO_ANIMATED_SPEC`(움직임) 두 프로필. 세트에 움직임이 하나라도 있으면
움직이는 프로필로 검사한다. **움직이는 규격은 개수·프레임·재생 시간·용량 상한이 전부 UNVERIFIED다.**
GIF가 만들어졌다는 이유로 제출 가능 판정을 내리지 않는다. 자동 제출은 구현하지 않았고 제공한다고 표시하지도 않는다.

- **QA/EXPORT ROLE**: 기계로 확인 가능한 규격 검사와 파일 이름/순서/묶음 자동화까지. 업로드·심사 설명·계정은 사용자 몫.

  애니메이션, 승인 예측, 자동 제출, 소셜 기능.
- **무료 완주**: 무료판에서 한 세트를 제작·저장·검사·내보낼 수 있다. 워터마크/결제/광고를 핵심 흐름의 조건으로 넣지 않는다.

## HOME / SET BOARD
HOME은 관리 폼이 아니라 **작업실**이어야 한다.
- 프로젝트 썸네일 중심
- 프로젝트명
- 완성 수 / 전체 수
- 원캐릭터 작은 이미지
- `+ 새 프로젝트`는 별도 단순 액션
- 긴 생성 폼을 홈에 상시 노출하지 않는다.

SET BOARD:
- 4열 슬롯 썸네일 그리드
- 현재 진행률
- 원캐릭터
- 완료/미완료 상태
- 관리 메뉴는 `…`로 숨김

슬롯 선택 시 Painter로 바로 진입한다.

## PAINTER — LOCKED
캔버스가 화면의 주인공이다.

상단:
- 홈
- 이전/현재/다음 칸
- 현재 슬롯 브리프
- 레이어
- 더보기

하단:
- `따라 그릴 참고` 스트립
- 펜/지우개/브러시/굵기/색상 등 최소 그림 도구
- 저장
- 저장 → 다음 칸

필수 기능:
- 자연스러운 펜 입력
- 기본 펜/연필/마커
- 지우개
- 펜·지우개 별도 굵기
- 충분한 색상 팔레트
- 그림 레이어 1/2
- 레이어 보임/숨김, 이동, 크기, 불투명도
- 여러 참고 이미지
- 참고 이미지 ON/OFF
- 참고 이미지 자체를 캔버스에서 직접 이동/확대/축소
- 원캐릭터 Quick View
- 한 손가락 드로잉
- 두 손가락 이동/핀치
- 두 손가락 짧은 탭 = 되돌리기
- 세 손가락 짧은 탭 = 다시 실행
- 투명 PNG
- 저장 → 현재 슬롯 반영
- 저장 → 다음 칸

Undo/Redo는 기본 화면 버튼으로 공간을 차지하지 않는다.
영어 `Draw Layer`, `Reference`, `CANON` 같은 사용자 노출 명칭을 피하고 `그림`, `참고`, `원캐릭터`를 사용한다.

참고 이미지는 캔버스 밑에 까는 작업 레이어이며 최종 Export에 포함하지 않는다.
참고 이미지는 타인의 결과물을 그대로 복제하기 위한 것이 아니라 포즈/표정/구도를 참고해 자기 캐릭터로 재창작하기 위한 자료다.

## REFERENCE TRANSFORM — LOCKED
`activeDrawLayerId`와 별도로 `activeReferenceId`를 유지한다.
- 참고 썸네일 탭 = 참고 ON/OFF 및 조정 대상 선택을 명확히 구분
- 활성 참고가 있을 때 두 손가락 이동 = **참고 이미지 자체 이동**
- 활성 참고가 있을 때 두 손가락 핀치 = **참고 이미지 자체 확대/축소**
- 참고 조정 대상이 없을 때만 캔버스 zoom/pan
- 펜/지우개를 선택하면 마지막 그림 레이어로 즉시 복귀

## LAYER ACCESS — LOCKED
레이어는 큰 모달로 캔버스를 가리지 않는다.
Infinite Painter의 작업성을 **상호작용 참고**로만 사용한다.
- 상단 레이어 버튼
- 우측의 좁은 플로팅 레이어 레일
- 그림/참고 레이어를 작은 썸네일 + 눈 아이콘으로 표시
- 선택/표시/숨김/추가를 즉시 처리
- 세부 opacity/transform이 필요할 때만 확장 패널

Infinite Painter의 시각 디자인이나 전체 구조를 복제하지 않는다.

## VISUAL SYSTEM V1.1 — LOCKED
목표 인상:
**밝고 친근하고 쉬워 보이지만, 어린이용이 아닌 성인 창작 작업실.**

### Base
- 전체 배경: 따뜻한 아이보리/웜그레이
- 주요 Surface/Card: 거의 흰색

권장 토큰:
- Background: `#F5F3ED`
- Surface: `#FFFFFF`
- Line: `#E7E2D8`
- Main Text: `#222222`
- Sub Text: `#7A766E`

### Accent Palette
파스텔 계열을 상태/강조/카드에 제한적으로 사용한다.
- Orange/Peach: `#FF8A4C`
- Yellow: `#F7C94A`
- Coral/Pink: `#EE6F7D`
- Mint: `#7BC6A4`
- Sky Blue: `#7DA9E8`
- Lavender: `#B9A2F2`

규칙:
- 한 화면의 강한 포인트색은 최대 2개 정도로 제한
- 기능 구분은 색만으로 하지 않고 위치/형태/간격으로 먼저 구분
- Painter는 특히 중립색 위주, 활성 도구/저장→다음만 포인트 사용
- 파스텔을 화면 전체에 남발해 유아용처럼 보이지 않게 한다.

### Shape / UI
- 둥근 모서리
- 충분한 여백
- 카드/버튼은 단순하고 큼직하되 장난감처럼 과장하지 않음
- 홈은 폼보다 썸네일/진행률 중심
- Painter는 카드 UI보다 작업 영역 우선

## DOODLE ART DIRECTION V1 — LOCKED
앱 안에 등장하는 캐릭터/보조 그래픽/빈 상태 일러스트/아이콘 보조 그림은 **귀엽지만 디테일하지 않은 러프한 두들 감성**으로 통일한다.

필수 성격:
- 단순한 형태
- 명확한 실루엣
- 약간 비뚤고 손으로 그린 듯한 선
- 작은 표정만으로 감정이 읽힘
- 평면적 표현
- 최소한의 색
- 완벽하게 정제된 벡터 느낌보다 손맛 우선

허용:
- 선 굵기의 미세한 불균일
- 살짝 어긋난 비율
- 러프한 낙서 느낌
- 단순한 얼굴/몸/소품

금지:
- 과한 입체감/그라디언트/렌더링
- 세밀한 질감/복잡한 명암
- 지나치게 정교한 캐릭터 일러스트
- 장난감/유아 학습앱 스타일
- 기업용 SaaS처럼 차갑고 무표정한 일러스트

그래픽이 사용자의 그림보다 지나치게 잘 그려져 `나도 못하겠다`는 인상을 주면 실패다.
앱 자체가 사용자의 러프한 창작을 자연스럽게 받아주는 분위기를 만들어야 한다.

## AI ROLE — LOCKED
> **V1 PRODUCT CANON으로 대체됨(2026-09-11).** 대사 추천·감정 편중 판정은 대체됐다. 규격/누락 검사는 유효하다.
AI의 핵심 역할은 **작업을 대신하는 생성이 아니라 세트 기획 보조 + 제출 전 사전심사/검수**다.

- 대사 후보 제안
- 대사 중복/감정 편중 경고
- 슬롯 구성 보조

최종 검수 단계:
- 규격 검사
- 누락 검사
- 세트 반복/중복 경고
- 원캐릭터 대비 일관성 검사
- 제출 준비 상태 판정

작업 중 불필요한 추천 버튼이나 긴 AI 설명으로 흐름을 끊지 않는다.
향후 레퍼런스 자동 분리·분류 같은 자동화는 생산성 기능으로 검토한다.

## QA
> **V1 PRODUCT CANON으로 대체됨(2026-09-11).** 원캐릭터 대비 편차와 반복 판정은 사람의 검토로 내려갔다.

- 누락
- 대사 중복
