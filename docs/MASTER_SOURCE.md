# EMOTICON STUDIO — MASTER SOURCE

## PRODUCT — LOCKED
휴대폰에서 **상업 이모티콘 1세트를 쉽고 빠르게 끝내는 전용 제작툴**.
일반 그림앱, 어린이 스티커 놀이앱, AI 완성그림 생성기가 아니다.

1차 타깃은 카카오/메신저 이모티콘 부업·작가 데뷔에 도전하는 성인 초보다.
전문 드로잉툴을 배우지 않아도 자신의 미감과 러프한 손그림으로 실제 제출 가능한 세트를 완성할 수 있어야 한다.
쉬워도 유치하지 않고 성인 창작 작업도구의 느낌을 유지한다.

제품 인상:
**“초보도 쉽게 시작할 수 있는, 귀엽고 러프한 두들 감성의 이모티콘 제작 작업실.”**
동시에 실제 상용 제출까지 이어지는 도구여야 한다.

## CORE UX — HIGHEST PRIORITY / LOCKED
제품의 본체는 Painter 한 화면의 연속 제작 흐름이다.

원캐릭터/참고 이미지 준비
→ 세트 기획(대사/무대사 + 참고 배치)
→ 01번 칸 Painter
→ 참고 이미지를 캔버스 밑에 켜고 직접 그림
→ 저장
→ 01번 슬롯 썸네일 자동 반영
→ 같은 Painter 흐름에서 02번 칸
→ 그려 저장
→ 반복
→ 1세트 완성
→ 자동 사전심사
→ 제출용 Export

핵심 리듬: **`그린다 → 저장 → 다음 칸 → 반복 → 1세트 완성`**.
작업 중 Home/상세/설정 화면을 반복 왕복하게 만들지 않는다.
Painter 화면 자체에서 `이모티콘 세트를 만들고 있다`는 맥락이 보여야 한다.

## SET PLANNING / SLOT BRIEF — LOCKED
대사/기획은 Painter 안에서 새로 고민하게 만드는 기능이 아니다.
Painter 진입 전에 세트 기획 단계에서 각 슬롯에 다음을 준비한다.
- 대사 또는 무대사
- 참고 이미지/포즈
- 필요 시 짧은 상황 메모

AI 대사 추천은 이 단계에서만 보조적으로 사용한다.
Painter 상단에는 큰 입력창 대신 현재 슬롯의 짧은 작업 브리프를 작게 표시한다.
예: `01 · 잘자`, `02 · 헐`, `03 · 무대사`.
탭하면 빠른 수정은 가능하되 작업 흐름을 방해하지 않는다.

## HOME / SET BOARD
HOME은 관리 폼이 아니라 **작업실**이어야 한다.
- 프로젝트 썸네일 중심
- 프로젝트명
- 완성 수 / 전체 수
- 원캐릭터 작은 이미지
- `+ 새 프로젝트`는 별도 단순 액션
- 긴 생성 폼을 홈에 상시 노출하지 않는다.

SET BOARD:
- 4열 슬롯 썸네일 그리드
- 현재 진행률
- 원캐릭터
- 완료/미완료 상태
- 관리 메뉴는 `…`로 숨김

슬롯 선택 시 Painter로 바로 진입한다.

## PAINTER — LOCKED
캔버스가 화면의 주인공이다.

상단:
- 홈
- 이전/현재/다음 칸
- 현재 슬롯 브리프
- 레이어
- 더보기

하단:
- `따라 그릴 참고` 스트립
- 펜/지우개/브러시/굵기/색상 등 최소 그림 도구
- 저장
- 저장 → 다음 칸

필수 기능:
- 자연스러운 펜 입력
- 기본 펜/연필/마커
- 지우개
- 펜·지우개 별도 굵기
- 충분한 색상 팔레트
- 그림 레이어 1/2
- 레이어 보임/숨김, 이동, 크기, 불투명도
- 여러 참고 이미지
- 참고 이미지 ON/OFF
- 참고 이미지 자체를 캔버스에서 직접 이동/확대/축소
- 원캐릭터 Quick View
- 한 손가락 드로잉
- 두 손가락 이동/핀치
- 두 손가락 짧은 탭 = 되돌리기
- 세 손가락 짧은 탭 = 다시 실행
- 투명 PNG
- 저장 → 현재 슬롯 반영
- 저장 → 다음 칸

Undo/Redo는 기본 화면 버튼으로 공간을 차지하지 않는다.
영어 `Draw Layer`, `Reference`, `CANON` 같은 사용자 노출 명칭을 피하고 `그림`, `참고`, `원캐릭터`를 사용한다.

참고 이미지는 캔버스 밑에 까는 작업 레이어이며 최종 Export에 포함하지 않는다.
참고 이미지는 타인의 결과물을 그대로 복제하기 위한 것이 아니라 포즈/표정/구도를 참고해 자기 캐릭터로 재창작하기 위한 자료다.

## REFERENCE TRANSFORM — LOCKED
`activeDrawLayerId`와 별도로 `activeReferenceId`를 유지한다.
- 참고 썸네일 탭 = 참고 ON/OFF 및 조정 대상 선택을 명확히 구분
- 활성 참고가 있을 때 두 손가락 이동 = **참고 이미지 자체 이동**
- 활성 참고가 있을 때 두 손가락 핀치 = **참고 이미지 자체 확대/축소**
- 참고 조정 대상이 없을 때만 캔버스 zoom/pan
- 펜/지우개를 선택하면 마지막 그림 레이어로 즉시 복귀

## LAYER ACCESS — LOCKED
레이어는 큰 모달로 캔버스를 가리지 않는다.
Infinite Painter의 작업성을 **상호작용 참고**로만 사용한다.
- 상단 레이어 버튼
- 우측의 좁은 플로팅 레이어 레일
- 그림/참고 레이어를 작은 썸네일 + 눈 아이콘으로 표시
- 선택/표시/숨김/추가를 즉시 처리
- 세부 opacity/transform이 필요할 때만 확장 패널

Infinite Painter의 시각 디자인이나 전체 구조를 복제하지 않는다.

## VISUAL SYSTEM V1.1 — LOCKED
목표 인상:
**밝고 친근하고 쉬워 보이지만, 어린이용이 아닌 성인 창작 작업실.**

### Base
- 전체 배경: 따뜻한 아이보리/웜그레이
- 주요 Surface/Card: 거의 흰색
- 본문/제목: 진한 차콜
- 경계선: 매우 옅은 웜그레이
- 다크 테마를 기본 방향으로 사용하지 않는다.

권장 토큰:
- Background: `#F5F3ED`
- Surface: `#FFFFFF`
- Line: `#E7E2D8`
- Main Text: `#222222`
- Sub Text: `#7A766E`

### Accent Palette
파스텔 계열을 상태/강조/카드에 제한적으로 사용한다.
- Orange/Peach: `#FF8A4C`
- Yellow: `#F7C94A`
- Coral/Pink: `#EE6F7D`
- Mint: `#7BC6A4`
- Sky Blue: `#7DA9E8`
- Lavender: `#B9A2F2`

규칙:
- 한 화면의 강한 포인트색은 최대 2개 정도로 제한
- 기능 구분은 색만으로 하지 않고 위치/형태/간격으로 먼저 구분
- Painter는 특히 중립색 위주, 활성 도구/저장→다음만 포인트 사용
- 파스텔을 화면 전체에 남발해 유아용처럼 보이지 않게 한다.

### Shape / UI
- 둥근 모서리
- 충분한 여백
- 카드/버튼은 단순하고 큼직하되 장난감처럼 과장하지 않음
- 홈은 폼보다 썸네일/진행률 중심
- Painter는 카드 UI보다 작업 영역 우선

## DOODLE ART DIRECTION V1 — LOCKED
앱 안에 등장하는 캐릭터/보조 그래픽/빈 상태 일러스트/아이콘 보조 그림은 **귀엽지만 디테일하지 않은 러프한 두들 감성**으로 통일한다.

필수 성격:
- 단순한 형태
- 명확한 실루엣
- 약간 비뚤고 손으로 그린 듯한 선
- 작은 표정만으로 감정이 읽힘
- 평면적 표현
- 최소한의 색
- 완벽하게 정제된 벡터 느낌보다 손맛 우선

허용:
- 선 굵기의 미세한 불균일
- 살짝 어긋난 비율
- 러프한 낙서 느낌
- 단순한 얼굴/몸/소품

금지:
- 과한 입체감/그라디언트/렌더링
- 세밀한 질감/복잡한 명암
- 지나치게 정교한 캐릭터 일러스트
- 장난감/유아 학습앱 스타일
- 기업용 SaaS처럼 차갑고 무표정한 일러스트

그래픽이 사용자의 그림보다 지나치게 잘 그려져 `나도 못하겠다`는 인상을 주면 실패다.
앱 자체가 사용자의 러프한 창작을 자연스럽게 받아주는 분위기를 만들어야 한다.

- 전문용어보다 `그림`, `참고`, `원캐릭터`, `다음 칸`처럼 바로 이해되는 단어 사용

## AI ROLE — LOCKED
AI의 핵심 역할은 **작업을 대신하는 생성이 아니라 세트 기획 보조 + 제출 전 사전심사/검수**다.

세트 기획 단계:
- 대사 후보 제안
- 대사 중복/감정 편중 경고
- 슬롯 구성 보조

최종 검수 단계:
- 규격 검사
- 누락 검사
- 세트 반복/중복 경고
- 원캐릭터 대비 일관성 검사
- 제출 준비 상태 판정

작업 중 불필요한 추천 버튼이나 긴 AI 설명으로 흐름을 끊지 않는다.
향후 레퍼런스 자동 분리·분류 같은 자동화는 생산성 기능으로 검토한다.

## QA
최종적으로 다음을 자동 검사한다.
- 필수 슬롯 수
- PNG/캔버스/투명영역/파일크기
- 누락
- 대사 중복
- 원캐릭터 대비 편차
- 슬롯 간 지나친 반복
- 제출 준비 상태

PASS/WARNING/FAIL은 사전검수이며 실제 플랫폼 승인을 보장하지 않는다.
공식 확인되지 않은 규격은 VERIFIED로 만들지 않는다.

## MONETIZATION — LOCKED
원칙: **완성은 무료, 생산성은 유료.**

FREE만으로 원캐릭터 등록 → 한 세트 제작 → 기본 Painter/Layer/Reference → 저장 → 기본 QA → 제출용 Export가 가능해야 한다.
무료판에서 Export, 슬롯 수, 저장 횟수, 상업 사용을 막거나 워터마크를 넣지 않는다.

PRO는 같은 일을 더 빠르고 편하고 전문적으로 만드는 기능이다.
후보: 고급 브러시/레이어, 손떨림 보정, 스포이드, transform 고도화, AI 분석, reference 자동화, 백업, 멀티플랫폼 export, batch export, 움직이는 이모티콘.
