# MANUAL QA DEFERRED — 사용자 실기기 직접 검수 목록

사용자 결정(2026-09-14): 라운드마다 BrowserStack 으로 멈추지 않고, 개발이 더 진행된 뒤 실제 Android 기기에서 한 번에 확인한다.
여기 적힌 항목은 **자동 검사만 통과**했거나 **실기기에서 확인되지 않은** 것이다. 확인하면 결과(PASS/FAIL·기기·날짜)를 옆에 적는다.
검수 빌드는 그 시점 소스로 새로 만든다(기존 보존 APK 는 최신 코드가 아니다).

- [ ] 320·360·390·412dp: 필요한 것 목록의 이름·남은 개수가 겹치지 않고 긴 한국어가 자연스럽게 줄바꿈되는가, 바닥 링크 두 개가 안전 영역 위에 있는가

- [ ] 일괄 적용: "무료로 쓸 수 있어요" 안내, PRO 설정일 때 회색 PRO 표시(빨간 오류 아님), 움직임 칸이 없을 때 이유·다음 행동 문장
- [ ] 부가 이미지: 회색 트랙 전환(아이콘/공유/대표), '지금까지 만든 것' 체크 줄
- [ ] 기준 그림 화면: 베이지 톤이 사라지고 흰/회색 바탕으로 보이는가
- [ ] 320·360·390·412dp: 설정 목록 줄·일괄 적용 안내·복구 화면 글자 잘림 없음

## 38.5차 — 손 감각 (코드·자동 검사로 판정할 수 없는 것만)
