## 1. 서비스 소개
`emoti 이모티`(이하 "앱")은 스마트폰에서 손가락으로 이모티콘을 그리고, 움직임을 붙이고, 한 세트를 파일로 만들어 내보내는 제작 도구입니다. 앱에는 회원가입과 로그인이 없습니다.

## 2. 처리하는 정보 — 한눈에 보기
| 구분 | 정보 | 어디에 있나 |
|---|---|---|
| 작업 데이터 | 그린 그림, 움직이는 파일(GIF·WebP), 내보내기 묶음(ZIP), 세트·캐릭터 이름, 성격·말투 메모, 칸별 대사·감정·상황, 문구, 움직임·브러시 설정, 색·팔레트, 보관한 움직임·조각 | **내 기기 안** 앱 전용 저장 공간 |
| 참고 이미지 | 사진 보관함에서 직접 고른 이미지의 사본 | **내 기기 안** |
| 이용권 표시 | PRO 이용권 종류, 확인 여부, 만료일, 확인 시각, 테스트 구매 여부 | **내 기기 안** |
| 결제 확인 정보 | 구매 토큰, 상품 번호(`pro_lifetime`), 플랫폼(`android`) | PRO 결제·복원·앱 실행 시 확인할 때 **운영자 서버로 전송** |

앱은 이름, 이메일, 전화번호, 주소, 위치, 연락처, 광고 식별자를 요청하거나 수집하지 않습니다. 앱에는 광고 도구와 이용 분석 도구, 오류 보고 도구가 들어 있지 않습니다.

## 3. 처리 목적
- **작업 데이터·참고 이미지**: 만들던 작업을 저장하고 이어서 작업하기 위해서입니다.
- **이용권 표시**: 어떤 PRO 기능을 열지 판단하기 위해서입니다.
- **결제 확인 정보**: PRO 구매가 실제로 이루어졌고 아직 유효한지 Google Play 에 확인하기 위해서입니다. 앱은 스스로 "구매했다"고 판단하지 않고, 운영자 서버가 Google Play 에 조회한 결과로만 PRO 를 엽니다.

## 4. 기기 내부에 저장되는 데이터
- 작업 데이터는 앱 전용 저장 공간에 저장되며, 운영체제가 다른 앱의 접근을 막습니다.
- 운영자는 작업 데이터의 사본을 받거나 보관하지 않습니다.
- 사진은 사용자가 사진 선택 화면에서 직접 고른 이미지만 앱 저장 공간으로 복사합니다. 사진 보관함 전체를 읽거나 목록을 만들지 않습니다. 선택·변환 과정에서 기기 캐시에 임시 파일이 남을 수 있으며, 기기의 캐시 정리나 앱 삭제로 지워집니다.
- **기기 백업**: Android 의 자동 백업 기능이 켜져 있으면 앱 저장 공간의 파일이 사용자의 Google 계정 백업에 포함될 수 있습니다. 이 백업은 Android 와 Google 계정 설정에 따라 이루어지며 운영자는 백업 내용에 접근하지 않습니다. 기기 설정에서 Google 백업을 끄면 앱 데이터도 백업되지 않습니다.

### 사용자 백업과 글꼴
- 백업 ZIP은 앱 폴더에 만들고 사용자가 공유 창에서 고른 앱으로 보냅니다. 운영자 서버로 자동 전송하지 않습니다.
- 되살리기는 `expo-document-picker`로 사용자가 직접 고른 백업 파일을 읽고 새 세트로 가져옵니다. 기존 작품을 덮어쓰지 않습니다.
- 휴지통의 세트는 기기 안에서 30일 보관합니다.
- 제목 글꼴 Jua는 앱에 포함된 로컬 파일이며 다운로드·전송하지 않습니다.
- 문의하기는 메일 앱에 앱 버전·OS 버전만 미리 채웁니다. 작품·세트 이름·파일을 자동 첨부하지 않습니다. 사용자가 메일을 보내면 메일 서비스가 처리합니다.

## 5. 결제 관련 정보
- 결제는 Google Play 가 처리합니다. 앱과 운영자는 카드번호 같은 결제 수단 정보를 보지 않습니다.
- PRO 를 구매하거나, "구매 복원"을 누르거나, 앱을 실행해 기존 구매를 다시 확인할 때, 앱은 **구매 토큰·상품 번호·플랫폼 세 가지**만 운영자의 영수증 확인 서버로 https 로 보냅니다. 그림, 이름, 기기 식별자는 보내지 않습니다.
- 운영자 서버는 이 정보로 Google Play 에 구매 상태를 조회하고, 확인 결과(확인 여부·이용권·확인 시각 등)만 앱에 돌려줍니다. 앱은 구매 토큰을 기기 저장 공간에 저장하지 않습니다.
- PRO는 한 번 구매하는 비소모성 상품 `pro_lifetime`입니다. 결제 내역·환불 문의는 Google Play 구매 내역에서 확인합니다.

구매 비활성 비공개 테스트(`EMOTICON_PURCHASES=closed`)에서는 가격 조회·구매·복원·실행 시 구매 재확인 및 영수증 요청을 하지 않습니다. 정상 출시 구성은 영수증 서버 검증이 필수입니다.

## 7. 보관 기간

- **앱의 구매 토큰**: 확인 요청 중에만 사용하고 기기에 저장하지 않습니다.
- **운영자 서버**: 서버 코드는 결제 확인 요청을 저장하지 않도록 작성되어 있습니다. 오류가 날 때 오류 내용이 서버 기록에 남을 수 있습니다. 현재 배포본은 서버를 쓰지 않으므로 서버 기록이 없습니다. 서버를 운영하기 시작하면 보관 기간을 이 항목에 적고 다시 시행합니다.

## 8. 삭제 방법
- **세트·컷 삭제**: 앱에서 세트를 지우면 기기 안 휴지통에 30일 보관되며, 기간이 지난 뒤 앱이 정리할 때 또는 사용자가 영구 삭제할 때 참조가 끊긴 이미지도 정리됩니다. 그림을 지운 경우 다른 작업이 참조하는 파일은 보존합니다.
- **전체 삭제**: 기기 설정에서 앱 데이터를 삭제하거나 앱을 삭제하면 기기 내 데이터가 모두 지워집니다. 내보내기 묶음(ZIP) 파일은 이 방법으로 지워집니다.
- 운영자는 기기 내 작업의 사본이 없어 **삭제한 작업을 복구해 드릴 수 없습니다.** 중요한 작업은 되살릴 수 있는 백업 ZIP으로 따로 보관하세요. 공유한 사본의 삭제는 공유 대상에서 직접 해야 합니다.
- **서버 기록 삭제 요청**: 문의 이메일(emoticon755@gmail.com)로 요청할 수 있습니다. 운영자는 법령이 정한 기간(요청 받은 날부터 10일) 안에 처리 결과를 알립니다.
