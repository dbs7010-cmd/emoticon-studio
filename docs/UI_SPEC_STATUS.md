## 덧붙임 (45.23 후속) — 명세 대조 두 건과 도구 상태 정리

| 항목 | 상태 | 근거 |
|---|---|---|
| **상단 모드행과 참고/레이어/문구 보조행이 한 줄** | **의도된 압축(기록)** | `src/painter/painter.tsx` 의 45.5차 주석: *"그림을 돕는 것끼리 한 무리 … 아래 도구 줄은 '지금 그리는 손'만 다룬다."* 모드 탭(그리기·움직이기)과 보조 셋(참고·레이어·문구)은 같은 48dp 줄에서 `flex:1` 로 갈라 선다. **이유**: 줄을 나누면 48dp 를 더 쓰고 그만큼 정사각 캔버스가 줄어든다. 640dp 높이에서 캔버스는 이미 한 변 320dp 로 화면의 52% 다(`viewport-and-scale.txt`). 근거 없는 생략이 아니라 캔버스를 지키려는 맞바꿈이므로 분리하지 않는다 |
