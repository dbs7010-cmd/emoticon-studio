## 남은 것

**차단(제품 결정·자료 필요)**
- X02 저장/파일 열기 — 시스템 저장 경로를 돌려주는 길이 없다.
- P01 약관·개인정보 URL — 법적 문서 주소는 발명하지 않는다.
- T01 도움말 — 쓸 내용이 없다.
- 최종 아트(360+ / 1024 마스터) · 브랜드/스토어 자료(FAIL 10 · WARN 1).

**미검증**
- 실기기 사용성 전반. 실제 화면·손가락 판정은 기기가 해야 한다.
- 글자 배율은 렌더된 스타일 계산이다. 실제 줄바꿈·글꼴 메트릭은 기기가 판정한다.

**부분**
- 보조 버튼 일부가 40~44dp 로, 명세의 48 보다 작다. 도구 줄처럼 촘촘한 자리라 한 번에 키우면 줄이 넘친다 — 화면별로 따로 볼 일이다.
