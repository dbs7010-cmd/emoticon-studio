# 이용약관 (초안)

## 1. 이 약관에 대하여
이 약관은 `임티제작소`(이하 "앱")을 쓰는 데 적용된다. 운영자는 `[[모름: 상호/사업자명]]`
(이하 "운영자")이다.

## 2. 앱이 하는 일
앱은 이모티콘 그림을 그리고, 움직임을 붙이고, 파일로 묶어 내보내는 도구다.
**앱은 이모티콘의 심사·승인·판매를 대행하지 않는다.** 카카오 이모티콘 스튜디오 제안과 심사는
카카오의 절차이며, 운영자는 그 결과에 관여하지 않는다.

## 3. 만든 작품의 권리
사용자가 그린 그림과 그 파일의 권리는 **사용자에게 있다.** 운영자는 사용자의 작품을 수집하지도,
전송받지도, 사용하지도 않는다. 결제 확인 때 서버로 가는 것은 구매 토큰뿐이고 작품은 포함되지 않는다(개인정보 처리방침 4항).

## 4. 사용자의 책임
사용자는 자신이 권리를 갖지 않은 그림·글꼴·상표를 작품에 넣지 않아야 한다. 그로 인한 분쟁의
책임은 사용자에게 있다.

## 5. 무료와 PRO
- 무료: 그리기 도구 전부, 전체 움직임 3종, 워터마크 없는 출력. 저장·출력 횟수 제한이나 강제 광고는 없다.
- PRO: 부분만 움직이기, 여러 동작 조합, 두 모습 교대, 움직임 보관·일괄 적용.
- 요금은 앱스토어/구글플레이를 통해 결제되며, **결제 화면에 표시되는 스토어의 금액이 실제 금액이다.**
- 해지·환불은 각 스토어의 정책을 따른다. 운영자는 스토어를 대신해 결제를 취소할 수 없다.
- **PRO 기간이 끝나도 이미 만든 작품과 파일은 지워지지 않고**, 저장해 둔 PRO 움직임은 계속 재생·출력된다.
  새로 만들거나 바꾸는 PRO 효과에만 이용권이 필요하다.

## 6. 데이터 보관과 삭제
작품은 기기 안에만 있다. 앱을 지우면 기기에 저장된 작품도 함께 지워지며, **운영자에게는 사본이 없어
복구해 줄 수 없다.** 중요한 작품은 내보내기로 따로 보관하기를 권한다.

## 7. 서비스 변경과 중단
운영자는 앱의 기능을 바꾸거나 중단할 수 있다. 중단하더라도 기기에 이미 저장된 작품에는 영향이 없다.

## 8. 책임의 한계
앱은 "있는 그대로" 제공된다. 운영자는 `[[모름: 준거법/관할]]` 이 허용하는 범위에서 책임을 진다.

# 개인정보 처리방침 (초안)

## 1. 한 줄 요약
이 앱은 이름·연락처·위치 같은 개인정보를 수집하지 않고, 계정도 없다.
**다만 PRO 를 결제하면 그 구매가 진짜인지 확인하기 위해 구매 토큰이 운영자 서버로 전송된다**(아래 4항).
그 밖의 작업 데이터는 기기 안에만 있다.

### 지금 배포본과 출시 예정본의 차이
| | 현재(영수증 확인 서버 미설정) | 출시 예정 |
|---|---|---|
| 결제 | 결제 모듈이 없어 구매가 진행되지 않는다 | 스토어 결제 후 구매 토큰을 서버로 보내 확인 |
| 외부 전송 | 없음 | 구매 토큰·상품 번호·플랫폼 (4항) |
이 방침은 **출시 예정 흐름을 기준으로** 쓴다. 현재 배포본에서는 4항의 전송이 일어나지 않는다.

## 2. 앱이 기기에 저장하는 것
| 무엇 | 왜 | 어디에 |
|---|---|---|
| 그림 파일(PNG), 움직이는 파일(GIF·WebP) | 작업을 이어서 하려고 | 기기 안 앱 전용 폴더 |
| 세트 이름, 문구, 칸 상태, 최근 쓴 색 | 같은 이유 | 같은 곳 |
| 보관한 움직임·그림 | 다른 칸에서 다시 쓰려고 | 같은 곳 |
| 이용권 표시(PRO 여부·기간) | 어떤 기능이 열리는지 판단하려고 | 같은 곳 |

이 가운데 이름·연락처·위치·연락처 목록·기기 식별자는 **하나도 없다.**

## 3. 밖으로 나가는 경우
- **공유하기**: 사용자가 직접 누를 때만, 사용자가 고른 앱으로 파일이 나간다. 그 뒤의 처리는 그 앱과
  사용자의 선택에 따른다.
- **사진 고르기**: 사용자가 고른 이미지를 앱 폴더로 복사한다. 보관함 전체를 읽거나 목록을 만들지 않는다.
- **결제**: 스토어(구글플레이/앱스토어)가 처리한다. 앱은 카드번호 같은 결제 정보를 보지 않는다.
### 4. 결제 영수증 확인 (출시 예정)
PRO 는 스토어 결제만으로 열리지 않는다. 그 구매가 진짜인지 운영자 서버가 구글 플레이에 직접
물어본 결과로만 열린다. 구현에 맞춰 적는다(`src/services/receipt.ts`, `server/verify-receipt.js`).

**앱이 서버로 보내는 것 — 이 세 가지가 전부다**
| 필드 | 값 | 왜 |
|---|---|---|
| `purchaseToken` | 스토어가 발급한 구매 토큰 | 이 토큰으로만 스토어에 조회할 수 있다 |
| `productId` | `pro_monthly` 또는 `pro_yearly` | 요청한 상품과 실제 구매가 같은지 대조 |
| `platform` | `android` | 어느 스토어에 물어볼지 |

이름·이메일·기기 식별자·광고 식별자·작품은 **보내지 않는다.** 앱은 카드번호 같은 결제 정보를 보지 못한다.

**서버가 하는 일**: 구글 플레이 Developer API 에 구독 상태를 조회하고(`purchases.subscriptionsv2`),
상품 번호·구독 상태·만료 시각을 확인해 `{ verified, plan, expiresAt }` 만 앱에 돌려준다.
서비스 계정 키는 서버에만 있고 앱에는 들어가지 않는다.

**앱이 기기에 남기는 것**: 돌려받은 플랜·만료일·확인 시각. 구매 토큰은 기기에 저장하지 않는다.

| 항목 | 내용 |
|---|---|
| 수신 서버 | `[[모름: 배포 주소·운영 주체]]` |
| 서버 보관 | `[[모름: 로그 보관 기간과 범위]]` — 결정되면 여기에 적는다 |
| 처리 위탁 | 구글(Google Play 결제·구독 상태 조회) / 호스팅 `[[모름]]` |
| 국외 이전 | `[[모름: 서버 지역]]` |

## 5. 제3자 제공·위탁
분석 도구, 광고 SDK, 크래시 리포트 도구는 쓰지 않는다.
결제와 구독 상태 확인은 구글(Google Play)을 거친다. 그 밖의 제공·위탁은 없다.

## 6. 아동
앱은 연령 정보를 묻지 않으며 개인정보를 수집하지 않는다.

## 7. 권리 행사
기기 안 데이터는 앱을 지우면 함께 지워진다. 결제 확인 과정에서 서버에 남는 기록의 열람·삭제는
`[[모름: 문의처]]` 로 요청할 수 있다(보관 범위가 정해지면 이 항목을 구체화한다).

## 8. 보안
작업 데이터는 기기의 앱 전용 저장 공간에 있고, 운영체제가 다른 앱의 접근을 막는다. 운영자는 작품의 사본을 갖지 않는다. 결제 확인 통신은 https 로만 보내며, 서비스 계정 키는 서버에만 둔다.

## 9. 변경
방침이 바뀌면 앱과 이 문서에서 알린다. 시행일 `[[모름: 시행일]]`
