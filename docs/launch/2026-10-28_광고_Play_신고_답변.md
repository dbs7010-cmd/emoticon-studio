# 광고(vc21) — Play Console 신고 · 처리방침 게시 (대표님 작업)

vc21 부터 Android 무료 이용자가 **파일 묶음 만들기(카카오·LINE) 전에 보상형 광고를 한 번** 봐요. PRO 는 광고 없음.
SDK: Google Mobile Ads(react-native-google-mobile-ads 17.4) · 광고 등급 PG 제한 · 동의 창(UMP, 필요한 지역만).
**vc21 을 올리기 전에 아래 1~3 을 먼저 끝내야 해요**(안 하면 Play 검토에서 거절될 수 있어요).

## 1. 개인정보처리방침 다시 게시
- 바뀐 파일: `site/privacy/index.html` (광고 관련 정보 줄 · AdMob 줄 · 개정 2026-10-28 추가)
- 평소처럼 운영자 게시 스크립트로 올려 주세요. **개정일(10월 28일)은 실제 게시한 날과 같아야 해요** — 다른 날 올리면 알려 주세요, 날짜를 고칠게요.

## 2. Play Console › 앱 콘텐츠
1. **광고** → "예, 앱에 광고가 포함되어 있습니다"
2. **광고 ID** → "예" → 용도: **광고 또는 마케팅** (분석·사기 방지도 Google SDK 가 쓰므로 함께 체크 권장)
3. **대상 연령층** → 지금 설정을 확인해 주세요. **13세 미만이 포함돼 있으면 알려 주세요**(가족 정책 — 광고 설정을 바꿔야 해요). 13세 이상만이면 그대로.

## 3. Play Console › 앱 콘텐츠 › 데이터 보안 (기존 답변에 **추가**)
Google AdMob 이 수집하는 항목(Google 공개 안내 기준):

| 데이터 유형 | 수집 | 공유 | 목적 |
|---|---|---|---|
| 기기 또는 기타 ID (광고 ID) | 예 | 예(Google) | 광고 또는 마케팅 · 분석 · 사기 방지·보안 |
| 대략적인 위치(IP 기반) | 예 | 예(Google) | 광고 또는 마케팅 · 분석 · 사기 방지 |
| 앱 활동 › 앱 상호작용(광고 클릭 등) | 예 | 예(Google) | 광고 · 분석 |
| 앱 정보 및 성능 › 비정상 종료 로그·진단 | 예 | 예(Google) | 분석 · 사기 방지 |

- 전송 중 암호화: **예** · 삭제 요청: 기존 답변 그대로(광고 데이터는 Google 계정·기기 광고 ID 재설정으로)
- 수집이 선택 사항인가: **아니요**(무료 이용자가 파일 묶음을 만들 때 광고가 뜸. 광고를 못 불러오면 그냥 만들어짐)
- 정확한 항목은 Google 안내 페이지 "Google Mobile Ads SDK 데이터 공개"와 한 번 대조해 주세요.

## 4. AdMob
- 앱 › emoti 이모티 › **앱 스토어 연결**: 프로덕션 출시 후 Play 스토어 등록정보와 연결
- **app-ads.txt**: 스토어 등록정보의 웹사이트 주소(도메인) 루트에 올려야 광고 수익이 제대로 나와요. 웹사이트 주소를 알려 주시면 파일 내용을 만들어 드릴게요.
- 지급 정보(은행·세금): 수익이 쌓이기 전까지 입력

## 5. iOS
AdMob 에 iOS 앱이 아직 없어요. iOS 빌드 전에 AdMob 에서 iOS 앱을 만들고 앱 ID(`ca-app-pub-…~…`)를 알려 주세요(없으면 iOS 앱이 시작할 때 멈춰요). 그때까지 iOS 는 광고를 쓰지 않도록 코드가 막아 둠.
