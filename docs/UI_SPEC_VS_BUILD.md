## 미결 4건 — **결정됨 (45.26)**

45.25 에 '근거를 찾지 못해 그대로 둔다'고 적었던 네 가지를 사용자가 결정했다. **더 이상 미결이 아니다.**

| # | 항목 | 시안 | 결정 | 상태 |
|---|---|---|---|---|
| 1 | 되돌리기 / 완료 | 머리줄 오른쪽 | **현재 하단 유지** | 확정 — 바꾸지 않는다 |
| 3 | 브러시 카드 | 캔버스 아래 상시 노출 | **상시 노출하지 않음**(선택판을 열어 고르고, 고르면 닫힌다) | 확정 — 바꾸지 않는다 |
| 5 | 하단 '색' 버튼 | 도구 줄에 없음(별도 시트) | **유지** | 확정 — 바꾸지 않는다 |
| 13 | 작업 도구 메뉴 | 문구·레이어·참고·움직임을 한 메뉴로 | **기존 진입점 유지, 새 재편 없음**(머리줄에 참고·레이어·문구, 움직임은 탭) | 확정 — 바꾸지 않는다 |

시안과 다른 것은 맞지만, 네 가지 모두 **지금 배치를 그대로 두기로 결정**했다. 앞으로 이 네 항목을 '미구현'이나 '미결'로 다시 올리지 않는다.
