# 임티제작소 UX 기준 (45.7차 고정)

> 이 문서는 사용자와 확정한 제품 기준이다. 이후 라운드는 새 기준을 발명하지 않고 이 문서에 맞춰 판단한다.
> 바꾸려면 사용자의 명시적 승인이 필요하다.

## 0. 제품 정의

전문 그림앱의 축소판이 아니다. **이모티콘 제작 전용 도구**다.
"전문 그림앱보다 훨씬 쉽지만, 장난감 그림앱처럼 보이지 않는다."

## 1. 최상위 원칙 (LOCK)

1. 기능 수를 무조건 줄이지 않는다. **한 순간에 생각해야 하는 기능 수**를 줄인다.
2. 자주 쓰는 기능은 바로 보인다.
3. 부가 기능·세부 설정은 필요할 때 펼쳐진다.
4. 그리는 동안 캔버스가 주인공이다.
5. 뜻이 분명한 아이콘은 이름을 생략할 수 있다(지우개·채우기). 추측해야 하는 것은 이름을 남긴다(선택).
6. 한 번 배운 조작은 앱 전체에서 같게 동작한다.
7. 패널을 열었다고 그림의 위치·크기·확대·이동이 변하지 않는다. (예외: OS 키보드가 화면 자체를 줄일 때)
8. 32칸 반복 제작이 늘 기준이다. 같은 설정을 매 칸 다시 하게 만들지 않는다.
9. 기능을 더하기 전에 "32번 반복하면 귀찮은가"를 먼저 묻는다.
10. 단순화를 이유로 확정된 기능을 삭제하지 않는다.

## 2. 화면 역할

- **홈 = 시작 화면**: 창작 표면 → [공지] → 표현 가이드 → 최근 1개 → 전체 보기. 관리 기능을 홈에 늘어놓지 않는다.
- **그리기 = 그림이 주인공**
  - 위: `[그리기][움직이기]  [참고][레이어 n][문구]`
  - 가운데: 캔버스(오른쪽 가장자리 굵기 띠 · 오른쪽 위 배율 · 위 알림 한 자리)
  - 아래: `[브러시][색] | [지우개][채우기][선택]` — 앞의 둘이 주요 기능, 뒤의 셋은 빠른 도구
- **움직이기 = 빠른 결과**: 고르면 즉시 미리보기 → 속도·세기 → 완료. 무료 움직임은 한 번 눌러 적용된다.
- **부분 움직이기(PRO)**: 움직일 부분 → 움직임 → 즉시 결과. 타임라인·전문 용어를 앞에 내놓지 않는다.

## 3. 기능별 기준

- **브러시**: 펜·붓·연필은 엔진에서 실제로 다른 획(진하기·굵기·결)을 그린다. 견본으로 고른다. 보정은 끄고 켜고 세기를 고를 수 있다. 굵기·선 종류·보정은 다음 칸에서도 이어진다. PRO 확장 자리를 막지 않는다.
- **색**: 최근 색이 가장 빠르고, 더 필요하면 팔레트·색상환·세부로 들어간다. 모든 기능을 항상 펼쳐 두지 않는다.
- **문구**: 입력 → 글씨체 → 색 → 배치가 끊기지 않는다. 키보드는 닫기·적용·다른 작업으로 넘어갈 때 남지 않는다.
- **레이어**: 큰 전문 패널을 만들지 않는다. 현재 장을 늘 표시하고, 펼치면 추가·삭제·복제·숨김·이름·**차례 바꾸기**를 한다(최대 4장).
- **참고**: 고른 자료 안에서는 좌우로 넘겨 본다. 다시 찾기로 격자로 돌아간다.

## 4. 판정 용어

- PASS: 기준과 구현이 같다
- MINOR: 구조는 맞고 작은 조정만 남았다
- FAIL: 확정 기준과 구현이 다르다 → 그 라운드에서 최소 수정
- UNVERIFIED: 코드로 판단 불가(실기기 필요) — 억지로 PASS 로 올리지 않는다
