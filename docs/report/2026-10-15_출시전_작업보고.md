# 출시 전 작업 보고 (2026-10-15)

근거 표기: **자동**(검사 스크립트) · **에뮬레이터** · **실기기** · **실서비스**. 실서비스에서 확인하지 않은 것은 완료라고 적지 않는다.
가격·결제 상품·스토어 설정은 바꾸지 않았다. 배포·업로드·Console 입력·공개 게시는 하지 않았다.

## 1. PRO가 무엇이 강해졌나
| 전 | 후 | 근거 |
|---|---|---|
| 부분 움직임 축이 그림 한가운데 → 팔이 칸 밖으로 휘둘림 | 레이어를 고르면 **몸 쪽 끝을 축으로 추정**(고칠 수 있음, 사용자가 옮긴 축은 건드리지 않음) | 자동 · 에뮬레이터 |
| 빈 상태에서 회전·각도·속도를 직접 맞춤 | 출발점 3개: **손 흔들기 · 귀 까딱 · 통통 튀기** | 자동 · 에뮬레이터 |
| 단계 연출을 빈 단계부터 만듦 | 조합 3개: **등장→인사 · 놀람→떨기 · 폴짝→신남**(고른 뒤 단계 화면에서 고침). '조합' 묶음 칩으로 바로 감 | 자동 · 에뮬레이터(칩은 자동만) |
| 무료 사용자는 부분·단계를 볼 수 없음 | 조합을 **자기 그림으로 미리 보기**(저장 시 PRO 안내, '원래대로'로 복귀) | 자동 |
| 구매 화면은 정지 그림 두 장 + 기능 이름 | **같은 그림 세 장**(무료 통통 / PRO 손만 흔들기 / PRO 등장→인사)을 앱 엔진으로 구운 실제 움직임으로 보임 | 자동(기기 화면 미확인) |

## 2. 반복이 얼마나 줄었나
- 칸마다: '이전 칸 그림으로 시작'이 **그림 + 움직임**을 함께 가져온다 → 자동 측정 11탭 → 6탭(**칸마다 −3탭**). 24칸이면 약 70탭.
- 손 흔들기: 예전 축 옮기기·회전 고르기·슬라이더 조절(탭 4번 이상 + 끌기 + 슬라이더 2번) → 출발점 한 번.
- 등장→인사: 예전 탭 5번 + 슬라이더 2번 → 조합 칩 + 조합 = 탭 2번.
- 기록: `docs/closed-test/25_동일그림_작업기록.md`(에뮬레이터, 시험자 1명 — 성공률이 아님).

## 3. 이번에 찾아서 고친 것 (같은 그림 작업 중)
1. 부분 움직임 + 쓱 등장 → 들어오는 동안을 '칸 밖'으로 잘못 경고 → 고침(회귀 검사: 고치기 전 실패 / 후 통과).
2. 같은 그림 + 다른 움직임 칸을 '같은 그림 파일'로 잘못 경고 → 고침(검사 추가).
3. 조합이 효과 17개 아래(스크롤 5번) → '조합' 칩.

## 6. 운영자가 할 일 (순서대로)
1. **통신판매업 신고증 받기**(정부24 처리 중) → 신고 번호 확인.
2. `https://play.google.com/console` → 왼쪽 아래 **설정 › 개발자 계정 › 계정 세부정보** (막힘 안내 배너의 '계정 세부정보 업데이트' 링크로도 감)
   - 입력: 사업자 등록 번호 · 전자상거래 라이선스 번호(통신판매업 신고 번호) · 대행사(신고 기관: 노원구청)
   - 기대 결과: '한국 개발자 추가 정보' 경고가 사라지고 검토 제출 버튼이 열림.
3. Play Console › emoti › 테스트 › **비공개 테스트** › 새 버전 → `dist/emoti-1.0.0-vc9-…aab` 업로드 → 검토 제출(이전에 저장만 한 vc7·vc8 초안은 버리거나 vc9로 교체).
   - 기대: 승인 뒤 테스터 휴대폰에서 vc9 업데이트, 작품 유지.
4. 결제 확인용: vc7(결제 열림) 계열을 라이선스 테스터로 설치 → 테스트 구매 → PRO 켜짐 → 앱 삭제·재설치 → 구매 복원.
   - 기대: 운영 DB `users/{uid}.pro.source=store`, `/receipt` 200 `verified:true`. (결제 열린 빌드가 필요하면 vc10 으로 새로 만든다.)
5. 실기기 확인: PRO 클라우드 백업 1회 → 다른 기기에서 되살리기 · 구글·네이버 로그인 · 탈퇴.
6. 네이버 로그인 검수 요청(문서 23).

## 8. 결정이 필요한 것 (추천)
1. **가격**: 설계 목표 19,900원 vs 이전 검토 추천 12,900원(현재 Console 입력값 6,900원). 추천 — **출시는 12,900원으로 시작하고 판매 데이터 뒤 올리기**(내려가는 가격은 신뢰를 깎고, 올리는 것은 신규에게만 적용된다). 19,900원으로 간다면 지금 PRO 비교 화면처럼 '내 그림으로 미리 보기'가 반드시 앞에 있어야 한다.
2. **클라우드 조건**(현재 약속: 1인 1GB · 지울 때까지 · PRO 끝나고 90일 뒤 알림 후 삭제 가능)
   - A 지금 그대로(추천 — 이미 처리방침에 게시됨, 사용량 0이라 비용 위험 낮음)
   - B 1GB → 500MB, 미접속 1년 알림 후 삭제
   - C 세트 수 제한(예 20세트)
3. **다른 로그인 사이 PRO 이전**: 지금은 처음 산 계정에만 묶임.
   - A 그대로 + 거절 문구에 '처음 산 계정 회사'를 알려 주기(추천 — 작업 작음, 악용 없음)
   - B 관리자 수동 이전(문의 → 관리자 화면에서 옮김)
   - C 계정 연결 기능(로그인 두 개를 하나로 — 작업 큼)
