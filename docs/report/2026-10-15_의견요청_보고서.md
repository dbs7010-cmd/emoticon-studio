## 1. 한 줄 소개

**"그리고, 톡 누르면 움직이는 이모티콘"** — 휴대폰에서 이모티콘 세트를 그리고, 움직임을 붙이고, **카카오 이모티콘 스튜디오 제안 규격**에 맞는 파일 묶음까지 만들어 주는 앱.

- 대상: 카카오·라인 이모티콘 작가가 되고 싶은 **초보·아마추어**, 그리고 휴대폰으로 빠르게 시안을 만들고 싶은 작가
- 핵심 차별점: 그림 실력이 부족해도 **움직임을 '고르기만' 하면** 움직이는 이모티콘이 되고, 제안용 파일(PNG · WebP · 아이콘)까지 앱 안에서 끝난다
- 플랫폼: Android(Expo SDK 57 / React Native). iOS 미지원
- 서버: Firebase(로그인 · 클라우드 백업 · 공모전 · 구매 확인)
- emoti는 카카오 공식 앱이 아니며, 제안은 작가 본인 이름으로 직접 한다

## 3. 전체 기능

### 3-1. 시작 · 계정
- 첫 화면 한 장 → **카카오 · 네이버 · 구글 로그인 필수**(무료·유료 모두)
- **작가명**: 처음에 한 번 정하면 변경 불가, 금지어 차단(서버 확인)
- 내 정보: 로그인 정보, PRO 상태, 클라우드 백업, 전체 백업 파일, 로그아웃 · 탈퇴(서버 데이터 삭제)

### 3-2. 홈 · 세트 관리
- 세트 하나 = 카카오 제안 한 번 분량(32칸 보드, 움직이는 세트는 24칸이 제안 기준)
- 홈: 화면 폭에 꽉 찬 공지 배너(자동 넘김) → 최근 세트 대표 카드(캐릭터가 통통 튀는 효과 · 진행 막대 · '이어 그리기') → 제안까지 남은 일 → 내 세트 목록
- 세트 보드: 칸 격자(완성·그리는 중·다음 칸 표시), 전체 재생, **채팅에서 써 보기**(대화창에 내 이모티콘을 넣어 크기·표정 확인)

### 3-3. 그리기
- 펜 · 연필 · 마커(+ PRO 브러시), 지우개, 채우기, 선택(크기·회전·반전·새 레이어로 분리)
- 레이어 최대 4장, 색 판(직접 선택 · 팔레트 · 스포이드 · 색 저장), 문구(글씨체 3종)
- 참고 사진 · 밑그림, 이전 칸 그림에서 이어 그리기, 두 손가락 되돌리기 / 세 손가락 다시 실행
- **표현 가이드**: 감정별(인사·슬픔·화남·놀람·일상) 82개 예시 그림을 밑그림으로 깔아 따라 그리기

### 3-4. 움직이기 (그림 한 장을 움직임)
- 전체 움직임 **20종**(무료 6 · PRO 14): 등장(뿅·쓱·빼꼼·쿵·사라지기) / 동작(통통·둥실·까딱·폴짝·끄덕·꾸벅·들썩·살랑·빙글) / 강조(흔들기·두근·부르르·덜덜·쾅·쭈욱)
- 세기 · 속도 조절, 칸 밖으로 잘리는지 점선 안내 + 자동 맞추기
- **손그림 떨림(신규, 무료)**: 선이 장마다 살짝 다시 그려진 듯 떨려 손그림 애니메이션 느낌
- PRO: 부분만 움직이기(팔·귀 등 레이어별 회전·이동·크기), 두 모습 번갈아, 단계로 잇기(최대 3단계), 여러 칸에 한 번에 적용, 움직임 보관

### 3-5. 애니메이션 (신규 — 장마다 그림 자체를 바꿈)
- 기존 이모티콘처럼 **프레임별로 그리는 기능**: 지금 그림이 1장, 복사한 2장을 고쳐 그림
- 앞 장 비춰 보기(옅은 보라), 장마다 보여 주는 시간(0.1~1초), 장 순서 바꾸기·삭제, 재생 미리보기
- 움직이기 효과와 함께 적용됨(예: 윙크 + 통통)
- **무료 3장 · PRO 24장**(카카오 규격 상한 24프레임)
- 그리기 화면 탭: 그리기 · 움직이기 · 애니메이션

### 3-6. 내보내기 (카카오 제안)
- 칸 격자 · 손볼 곳 · **제출 준비 체크**(이모티콘 수 · 움직이는 WebP · 아이콘)
- 부가 이미지: 아이콘(78×78) · 공유 이미지 · 대표 이미지
- 파일 묶음: PNG + 움직이는 칸 프레임(카카오 WebPAnimator용 360×360 PNG) + WebP/GIF + 안내 문서
- 규격 출처: 카카오 이모티콘 스튜디오 공식 가이드(360×360, 24프레임 이하, 650KB 이하 등)

### 3-7. 강좌 (신규)
- 아래 탭 '강좌'. 공식 무료 강좌 **10편**: 앱 사용법 6(첫 세트 · 브러시/레이어/색 · 움직이기 · 애니메이션 · 내보내기 · 공모전) / 그리기 기초 3(캐릭터 정하기 · 표정 24가지 · 승인에 가까운 세트 구성) / 작가용 1(강좌 만드는 법)
- 한 편 = 단계별 실제 앱 화면 영상 또는 사진 + 설명 → 핵심 정리 3줄 → '바로 해 보기' 버튼
- 영상은 앱 안에 포함(인터넷 없이 재생, 전체 2.1MB)
- **유튜브 쇼츠용 세로 영상 10편** 별도 제작(배경음악 + 자막, 나레이션 없음) — 업로드 예정
- '작가 강좌(유료)' 자리는 '준비 중'으로만 표시

### 3-8. 공모전
- 앱 안 공모전: 열린 공모전 확인 → 세트 고르기 → 참가 조건 동의 → 세트 전체 제출 → 접수번호
- 같은 공모전에 한 세트만, 서버가 접수 확인 · 결과 발표 표시
- 구상: 공모전 선정 작가 → 강좌 작가로 연결

### 3-9. 운영 · 관리
- 관리자 웹: 공모전 관리, 회원 검색, 체험 PRO 지급/종료, 환불된 구매 동기화
- 개인정보처리방침 게시, 계정 삭제 URL, 데이터 보안 양식 제출

### 3-10. 디자인
- 흰 바탕 + 노랑(주 행동, 30%) + 보라(지금·선택·진행, 10%) + 점토(클레이) 질감 카드
- 홈 효과: 들어올 때 차례로 떠오름, 캐릭터 통통 · 반짝이, 진행 막대 채워짐, 버튼 빛 지나감(동작 줄이기 설정 시 멈춤)

## 4. 수익 구조

### 4-1. 현재 확정: 무료 + PRO 한 번 구매
| | 무료 | PRO (6,900원 · 평생 · 1회 결제) |
|---|---|---|
| 세트 · 그리기 · 내보내기 | 전부 | 전부 |
| 움직임 | 6종 + 손그림 떨림 | 20종 + 부분 움직임 · 두 모습 · 단계 잇기 · 여러 칸 한 번에 |
| 애니메이션 | 3장 | 24장 |
| 브러시 | 기본 | PRO 브러시 |
| 클라우드 백업 | 없음(파일 백업만) | 1인 1GB |
| 강좌 · 공모전 | 무료 | 무료 |

- Google Play 결제(수수료 15%) → 1건당 실수령 약 5,865원(부가세 별도 고려 필요)
- 서버 비용 예상(Firebase): PRO 1,000명 + 공모전 1,000건 기준 **월 약 800원**, 10,000명 기준 월 약 1만 원 → 비용 부담은 매우 낮음
- 구독이 아닌 평생 구매로 정한 이유: 진입 장벽을 낮추고 '한 번에 끝'이라는 단순함

### 4-2. 보류한 아이디어 (작가가 생긴 뒤 검토)
1. **유료 작가 강좌**: 공모전 선정 작가 · 카카오/라인 출시 작가(프로 인증)가 강좌를 올리고 판매. 유료 강좌는 실습 파일·과제 필수(유튜브와 차별), 첫 강 무료 미리보기, 작가 정산(예: 수수료 제외 70%)
   - 작가 단계안: 아마추어(무료 강좌만) → 신인(공모전 선정 또는 평점 4.5+·수강 100+) → 프로(출시 이력 인증, 관리자 승인)
2. **앱 내 재화 '콘(🌽)'**: 얻기만 하는 포인트(세트 완성 5콘, 프로 인증 1,000콘 등). 핵심 기능을 콘으로 잠그면 번거롭고 PRO 판매와 충돌해서 **보류**. 쓰게 된다면 PRO 체험권 · 효과 스티커 · 강좌 할인 정도로 검토

### 4-3. 앞으로 검토 중인 PRO 가치 추가
- 움직이는 효과 스티커(물음표 · 반짝이 · 하트 · 땀 · 화남 기운 등)
- 카메라 연출(확대 · 동그란 틀)

## 5. 홍보 계획

- **유튜브 쇼츠**: 강좌 10편을 세로 영상으로 준비(배경음악·자막). 영상 설명란에 앱 설치 링크
- **공모전**: 앱 안 공모전으로 사용자 유입과 '작가 데뷔' 동기 부여 → 선정작 홍보 · 선정 작가 강좌로 연결
- **스토어**: 스크린샷 5장 · 설명문 준비 완료. 키워드: 이모티콘 만들기, 움직이는 이모티콘, 카카오 이모티콘 제안
- **SNS**: 첫 게시물 · 테스터 모집 문구 초안 있음
- 아직 없는 것: 광고 예산 계획, 인플루언서/작가 협업, 커뮤니티(오픈채팅·카페) 운영, 리뷰 유도 장치

## 6. 알려진 약점 · 위험

1. **움직임 품질**: 기존 인기 이모티콘(예: 고라파덕)은 장마다 그림이 바뀌는데, 이번에 애니메이션 탭을 넣었지만 아직 실사용자 검증 전
2. **iOS 없음**: 이모티콘 작가 중 아이패드 사용자가 많을 가능성
3. **카카오 의존**: 카카오 규격·정책이 바뀌면 영향. 승인을 보장할 수 없음(앱은 '제안 준비'까지만 도움)
4. **1인 개발 · 운영**: 공모전 심사, 강좌 제작, 고객 문의를 혼자 감당
5. **실기기 미확인 기능**: 클라우드 백업 · 공모전 접수 · 실제 결제 · 애니메이션 내보내기 파일
6. **가격**: 6,900원 평생이 싼지 비싼지, 구독이 나은지 미검증
7. **유입**: 비공개 테스터 확보 외에 실제 마케팅 경험·예산 부족

## 7. 의견을 구하는 질문

1. **포지셔닝**: '초보 이모티콘 작가 도구'와 '그냥 재미로 내 이모티콘 만들기(일반인)' 중 어디에 집중해야 할까? 둘 다 잡을 수 있을까?
2. **가격**: PRO 6,900원 평생 구매가 적절한가? 구독(월/연), 더 높은 평생가, 무료 범위 조정 중 무엇이 나은가?
3. **무료/PRO 경계**: 애니메이션 무료 3장 · 움직임 무료 6종이 '써 보고 사고 싶게' 만드는 선으로 적절한가?
4. **유료 강좌 마켓플레이스**: 작가가 아직 없는 상태에서 언제, 어떤 조건이 되면 시작해야 하나? 유튜브 무료 강좌와 경쟁할 수 있는 차별점은?
5. **공모전**: 상금/혜택 없이도 참가자가 모일까? 초기 공모전을 어떻게 설계해야 유입·바이럴에 도움이 될까?
6. **홍보 우선순위**: 예산이 거의 없을 때 유튜브 쇼츠 · 인스타 릴스 · 틱톡 · 이모티콘 작가 커뮤니티 · 블로그 중 어디부터?
7. **출시 전 꼭 해야 할 것**: 지금 기능 중 빼거나 숨겨야 할 것, 반드시 더해야 할 것은?
8. **위험**: 카카오 관련 상표·정책 측면에서 조심해야 할 표현이나 기능이 있을까?
9. **수익 예상**: 이 구조로 현실적인 첫 6개월 다운로드·전환율·매출 범위를 어떻게 잡아야 할까?
