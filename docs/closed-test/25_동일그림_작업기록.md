### 파일 안쪽 검사 — 무엇을 못 했나 (두 가지를 구분)
1. **앱 내부 파일**: 출시 서명(디버그 불가) 빌드라 `run-as` 로 앱 폴더를 읽을 수 없다 — 의도된 보호.
2. **사용자가 공유로 내보낸 파일**: 에뮬레이터의 ZIP 공유 대상은 드라이브 · Gmail · Nearby · 블루투스 넷뿐(`query-activities` 확인), 모두 계정 로그인·다른 기기가 필요하다. 공유를 받아 저장하는 시험용 앱을 만들어 설치하려 했으나 **설치 권한이 허용되지 않아 하지 못했다.** → 내보낸 ZIP 의 안쪽(파일 수·360×360·용량·장 수·움직임)은 아직 **기기 파일로 확인하지 못했다.** 같은 코드 경로는 자동 검사(`export-test` · `flow-test` · `spec-test`)로만 확인.
