## 3. 이 표에 **들어 있지 않은** 비용
- **부가세 10%**(Google Cloud 청구서에 별도) · 환율 변동 · 카드 해외 결제 수수료
- Cloud Functions 실행(월 200만 회 무료 — 로그인·접수 확인 정도면 무료 한도 안으로 예상, 공모전 ZIP 검사가 많으면 초과 가능)
- Secret Manager(비밀 3개 — 무료 6개 버전 안), Hosting 전송(일 360 MB 무료), Cloud Logging(월 50 GiB 무료)
- 서버 함수 이미지 저장(Artifact Registry, 배포할 때마다 생김 — 0.5 GB 무료 넘으면 GB당 약 130원/월, 오래된 이미지 정리 정책 권장)
- Google Play·App Store 수수료, Apple 개발자 등록비(20번 문서), 도메인, 운영 인건비
- 앱 무결성 검사(App Check) 등 앞으로 붙일 보안 기능, 결제 영수증 검증 서버(결제는 아직 닫혀 있음)
- 사용자가 1 GB 상한까지 백업하는 극단적 사용(가정보다 많이 쓰면 저장비가 비례해서 는다)

## 4. 비용을 묶는 장치(있는 것)
- 1명 백업 상한 1 GB, 공모전 묶음 120 MB 상한, 같은 파일은 한 번만 저장(내용 해시), 바뀐 칸만 전송
- 끊긴 업로드 24시간 뒤 정리, 거절된 묶음 즉시 삭제
- 보관 기간 설정값(지금은 세기만 — 정책 확정 뒤 자동 삭제를 켜면 보관량이 줄어든다)
- 예산 알림(18번 문서 1-2) — **알림일 뿐 비용을 멈추지 않는다**
