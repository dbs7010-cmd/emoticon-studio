## 6. 결제 열린 시험 빌드 (클로드)
- `EMOTICON_PURCHASES` 를 닫지 않고 `EMOTICON_RECEIPT_ENDPOINT=https://emoti-18d80.web.app/receipt` 로 빌드. 결제가 열리면 **PRO 체험은 꺼진다**(설정이 두 가지를 함께 못 쓰게 막음).
- 비공개 테스트에 올림 → 운영자 휴대폰(라이선스 테스터)으로: 구매 → PRO 켜짐 → 앱 삭제 없이 '구매 복원' → 관리자 화면에서 회원 PRO(store, sandbox) 확인 → (선택) Play Console 에서 테스트 주문 환불 → 다음 날 PRO 닫힘 확인
