# vc4 계정·클라우드·공모전 — 개인정보처리방침·Play 데이터 보안 변경 초안 (2026-10-07, 게시 전)

> 상태: **초안.** 서버(Firebase)를 실제로 연결하는 빌드를 내기 **전에** 운영자 검토 후 게시한다. vc4 빌드는 서버 설정이 없어 아래 처리를 하지 않는다(앱은 '준비 중'만 표시).
> 근거 코드: `server/firebase/*`(규칙·함수), `src/services/cloud/*`, `src/components/cloud-screen.tsx`.

## A. 처리방침에 더할 내용
| 구분 | 정보 | 어디에 · 누가 | 목적 | 보관 |
|---|---|---|---|---|
| 계정 | 로그인 제공자(카카오·네이버·구글), 제공자가 준 회원 식별자(카카오 회원번호·네이버 고유 ID·구글 uid), 가입·최근 로그인 시각 | 운영자 서버(Firebase, Google LLC, **미국 us-central1**) | 로그인 유지, 내 백업·접수 구분 | 탈퇴할 때까지 |
| 작가명 | 회원이 정한 작가명(한 번 정하면 변경 불가, 2~12자) | 〃 | 앱 안 표시 · 앞으로 공모전·스토어 표시 | 탈퇴할 때까지(탈퇴 시 삭제·이름 반환) |
| 구글 로그인 | **구글 고유 식별자(sub)만** — 2026-10-08 서버 중계로 바꾸며 이메일·이름을 요청하지 않음(`openid` 범위만) | 〃 | 로그인 | 탈퇴할 때까지 |
| PRO 상태 | 체험/구매 여부, 출처(trial·admin·store), 확인 시각 | 〃(서버만 기록) | 클라우드 백업 권한 | 탈퇴할 때까지 |
| PRO 클라우드 백업 | 사용자가 올린 세트의 편집 원본(그림·레이어·움직임·문구·참고 사진 사본), 세트 이름·기기 이름, 사용량 | 〃 | 기기 변경·재설치 복원 | 사용자 삭제·탈퇴 때까지. **PRO 종료 후 처리는 운영자 결정**(제안: 읽기·내려받기 90일 → 삭제 예고 → 삭제) |
| 공모전 접수 | 제출한 세트 전체 묶음(ZIP), 세트 이름, 동의 버전·시각, 접수번호, 심사 상태 | 〃 | 심사·결과 발표·선정작 출품 준비 | 제안: 비선정작은 결과 발표 후 90일 삭제, 선정작은 출품 절차 완료 후 1년 — **운영자 결정** |
| 접속 기록 | IP 주소 등 요청 메타데이터 | Google Cloud 로그 | 보안·장애 대응 | Google 기본 보관 기간(운영자가 설정 확인) |

- **국외 이전**: 위 항목을 미국(Google LLC, Firebase us-central1)에 저장 — 이전 항목·국가·일시와 방법(서비스 이용 시 네트워크 전송)·보유 기간·거부 방법(로그인하지 않으면 이전 없음, 기기 저장·파일 백업은 그대로 사용)을 적는다.
- **처리 위탁**: Google LLC(Firebase: 인증·데이터베이스·파일 저장·서버 함수·관리자 페이지 호스팅).
- 카카오·네이버·구글: **운영자 서버가 각 회사 로그인을 직접 끝내고**(인가 코드 방식) 회원 식별자만 받는다. 회사 토큰은 확인 뒤 저장하지 않는다. 이메일·전화번호 등 추가 정보를 요청하지 않음(카카오 동의항목·네이버 제공 정보 설정과 일치시킬 것 — 18번 문서).
- **로그인 필수(2026-10-08 운영자 결정)**: 앱을 쓰려면 로그인한다. 작품은 여전히 기기에 저장되고, 서버에는 위 표의 것만 간다.
- 구매 권한은 백업 파일·클라우드 백업으로 옮겨지지 않는다(구매 복원으로만).
- **탈퇴**: 앱 › 설정 › 계정·클라우드 › 탈퇴 → 서버의 백업·회원 정보·공모전 접수·로그인 계정 삭제(기기 안 작품은 그대로). **앱 밖(웹) 삭제**: `https://<프로젝트ID>.web.app/account/` — 로그인 뒤 확인하고 바로 삭제(2026-10-10 구현, 에뮬레이터 확인). Play Console '계정 삭제 URL'에 이 주소를 적는다.

## C. 운영자 결정(이 문서로 확정할 것)
1. PRO 종료 후 클라우드 백업 보관 기간·안내 방식.
2. 공모전 접수 보관 기간(비선정·선정).
3. 웹 계정 삭제 요청 경로(메일 / 웹 양식).
4. 서버 지역(비용표의 us-central1 = 무료 한도 적용) 확정 — 서울로 하면 무료 한도 없음.
