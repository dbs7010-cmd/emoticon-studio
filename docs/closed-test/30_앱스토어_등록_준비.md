# App Store 등록 준비 (2026-10-27 시작)

> AAB 는 Android 전용이다. iOS 는 같은 코드로 **EAS Build(클라우드)** 가 .ipa 를 만들어 App Store Connect 에 올린다(Mac 불필요).
> 상태 표기: DONE(코드·테스트) · OPERATOR(대표님) · NEXT(내가). iOS 기기·빌드에서 확인한 것은 아직 없다.

## 1. 코드 준비 상태
| 항목 | 상태 | 내용 |
|---|---|---|
| Apple 로그인(지침 4.8 필수) | DONE(미검증) | 시작 화면 맨 위 Apple 버튼(iOS·사용 가능할 때만). 앱 `signInWithApple` → 서버 `exchangeApple` 이 Apple 공개키로 서명·iss·aud·exp·nonce 확인 → `apple:<sub>` 계정. 이메일·이름 요청 안 함. 서버 테스트 `server/firebase/test/apple.cjs` PASS |
| 탈퇴 시 Apple 토큰 철회(지침 5.1.1(v)) | DONE(미검증) | 로그인 때 authorizationCode → refresh_token(서버 전용 `appleTokens/<uid>`, 앱 접근 불가), 탈퇴 때 `/auth/revoke` |
| iOS 설정 | DONE | `app.json` ios: 번들 ID `com.emoticonstudio.app` · buildNumber 1 · usesAppleSignIn · 암호화 신고 면제(ITSAppUsesNonExemptEncryption=false) · 한국어 기본 · 아이패드 지원(supportsTablet) |
| **iOS PRO 결제(인앱결제)** | **NEXT — 출시 전 필수** | 지금 결제는 Google Play 전용. 지침 3.1.1: iOS 에서 PRO 를 팔려면 App Store 인앱결제. 지침 3.1.3(b): 다른 플랫폼 구매를 iOS 에서 쓰게 하려면 iOS 에서도 같은 상품을 인앱결제로 팔아야 함. → expo-iap iOS 구매 + 서버 App Store Server API 확인(인앱결제 키 .p8 필요) |
| 아이패드·태블릿·폴드 화면 | NEXT | 대표 요청(10-27): 폴드8 이상·갤럭시 탭·아이패드 기기 점검. 아이패드를 지원하면 아이패드 스크린샷 13" 도 필요 |
| iCloud 백업 제외 | NEXT | 내보낸 사본(exports/)을 백업 제외로 |

## 2. 대표님이 하실 일(순서대로)
1. **Apple Developer Program 가입** — developer.apple.com/programs (연 USD 99, 본인 인증). 개인 또는 사업자(사업자면 D-U-N-S 번호 필요).
2. **Expo 계정** — expo.dev 가입 → 이 프로젝트를 연결(제가 `eas init` 으로 연결, 로그인은 대표님이 터미널에서 `npx eas login`).
3. **App Store Connect › 앱 › +** — 플랫폼 iOS · 이름 `emoti 이모티` · 기본 언어 한국어 · 번들 ID `com.emoticonstudio.app` · SKU `emoti-ios`.
4. **Certificates, IDs & Profiles › Identifiers › com.emoticonstudio.app** — `Sign In with Apple` 켜기(EAS 가 자동으로 켜 줄 수도 있음).
5. **Keys › +** — `Sign in with Apple` 키 만들기 → .p8 내려받기(한 번만 받을 수 있음). Key ID · Team ID 를 저에게 알려 주시고(공개값), .p8 은 **채팅에 붙이지 말고** 서버 비밀값으로 넣기:
   `firebase functions:secrets:set APPLE_SIGNIN_KEY` (파일 내용 붙여 넣기) — 그다음 서버 배포는 제가 명령을 드림.
6. **인앱결제 상품** — App Store Connect › 앱 › 수익화 › 인앱 구입 › 비소모성 · 제품 ID 는 Android 와 같은 이름 권장 · 가격 19,900원(출시 할인은 App Store 의 '가격 프로모션' 별도) · 심사용 스크린샷.
7. **유료 앱 계약** — App Store Connect › 비즈니스 › 유료 앱 계약 · 세금 · 은행 정보(없으면 인앱결제가 안 됨).
8. **EAS 환경 변수**(expo.dev › 프로젝트 › Environment variables, production): `EMOTICON_FIREBASE_CONFIG`(Android 빌드와 같은 공개 웹 설정 JSON) · `EMOTICON_LOGIN=kakao,naver,google` · `EMOTICON_RECEIPT_ENDPOINT`.
9. **iPhone 실기기**(TestFlight 앱) — 로그인·그리기·움직이기·내보내기·결제 확인.

## 3. 심사 자료
- 스크린샷: iPhone 6.9"(1320×2868 또는 1290×2796) 필수, 아이패드 지원 시 13"(2064×2752) 필수.
- 앱 개인정보 보호 라벨(Play 데이터 보안과 같은 내용: 식별자·구매·사용자 콘텐츠, 추적 없음).
- 심사용 로그인: Apple 로그인으로 심사관이 직접 가능. 메모에 "Apple로 계속하기로 로그인" 안내.
- 계정 삭제: 앱 안 내 정보 › 탈퇴(웹 탈퇴 페이지도 있음).
- 공모전·체험단: 앱 안에서 직접 그린 작품 제출 — 상금이 PRO 사용권뿐이라 지침 5.3(경품) 문구를 심사 메모와 공모전 규정에 '애플은 후원자가 아님'으로 넣기.

## 4. 빌드 명령(가입 후 제가 실행)
```
npx eas build --platform ios --profile production
npx eas submit --platform ios --latest
```
