# 실제 폰 화면 녹화 순서 (스토어 스크린샷 · SNS 영상용)

- 반드시 **비공개 테스트 트랙에서 받은 앱**(출시 구성)으로 찍는다.
- 내부 검수 APK(`internal-review`)에는 설정에 검수용 PRO 스위치가 보여 쓰면 안 된다.
- 개발자 모드·ADB는 필요 없다. 폰 빠른 설정의 **화면 녹화**만 쓴다.

## 준비
1. 알림을 끈다(방해 금지 모드). 배터리·시계가 너무 낮거나 이상한 값이 아닌지 본다.
2. 화면 녹화 설정: 소리 없음, 터치 표시 켜기(보는 사람이 어디를 누르는지 알 수 있게).
3. 연습용 세트 하나를 미리 만들어 둔다. 칸 몇 개를 그려 두면 보드·홈·내보내기가 비어 보이지 않는다.

## 영상 A — 한 세트 흐름(약 60초, SNS 1·2번과 스토어 스크린샷용)
| 초 | 화면 | 할 일 |
|---|---|---|
| 0~5 | 홈 | 잠깐 멈춰 홈 전체를 보여 준다(이어서 만들기 · 제안까지 남은 일) |
| 5~10 | 홈 → 세트 만들기 | '새 이모티콘' → 만들기 |
| 10~30 | 그리기 | 01번 칸에 얼굴을 그린다(기본 펜 → 굵기 조절 → 색 한 번 바꾸기). 두 손가락 톡으로 되돌리기 한 번 |
| 30~40 | 움직이기 | '통통' → 세기 조절 → 캔버스가 움직이는 것을 2초 보여 준다 |
| 40~45 | 저장 | '저장' → 초록 안내('01번 칸 저장했어요') |
| 45~52 | 다시 열기 | 뒤로 → 보드 → 01번 칸 다시 열기 → 그림과 움직임이 그대로 |
| 52~60 | 내보내기 | 보드 → 내보내기 → 파일 묶음 만들기 → 공유 창까지 |

## 영상 B — 움직임 모음(약 15초, SNS 2번용)
움직이기 탭의 효과 격자를 보여 준 뒤, 무료 효과 3개(뿅 · 통통 · 흔들기)를 차례로 눌러 각각 2~3초씩 캔버스를 보여 준다.

## 스크린샷(영상에서 잘라도 됨, 휴대전화 세로)
1. 홈
2. 그리기(그림이 있는 상태)
3. 움직이기(효과 격자)
4. 브러시 목록
5. 내보내기 검수
6. 세트 보드

**주의:**
- 테스터의 작품이나 남의 캐릭터를 쓰지 않는다. 운영자가 직접 그린 그림만 쓴다.
- 대체 렌더 이미지(`verification/…/screens`)는 스토어·SNS에 쓰지 않는다.
