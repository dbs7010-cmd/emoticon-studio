# 테스터 보상 — PRO 지급 방법 검토와 제안

- 사용자 결정(2026-09-27): **보상으로 PRO 제공 가능.** 기간·대상·지급 방법은 미정이다.
- 그래서 모집글에는 '평생' 같은 기간 표현을 쓰지 않는다.

## 1. 지금 구조에서 PRO가 생기는 길

- 앱이 PRO로 인정하는 조건은 하나뿐이다(`src/services/pro.ts` `isPro`).
  - 스토어 구매(`source:'store'`)를 **우리 영수증 서버가 Google Play에 확인**(`verified:true`)한 경우
  - 기한이 있다면 그 기한 안
- 저장 파일을 손으로 고친 이용권은 출시 빌드에서 통하지 않는다.
- 검수용 해제(`reviewUnlock`)는 이용권이 아니다. 내부 검수 빌드·개발 실행에서만 동작한다.
  - 45.40 C7부터 **구매를 닫은 테스트 빌드에서는 검수용 스위치 자체가 꺼진다.**
  - 그 빌드를 `internalReview`와 함께 만들면 빌드가 멈춘다.

## 3. 제안하는 지급 방식(A)

**지급 시점:**
- 비공개 테스트 빌드는 **구매가 닫혀 있어**(C7) 테스트 중에는 코드를 쓸 수 없다.
- 그래서 지급은 **PRO 구매가 열리는 빌드**(PRO 결제 테스트 뒤 정식 출시 등)가 나온 뒤다.

**필요한 것:**
1. Play 개발자 계정과 앱
2. `pro_lifetime` 상품 등록·활성화
3. 영수증 서버 배포와 빌드에 서버 주소
4. PRO 결제 테스트 통과(`06_PRO테스트계획.md` P1~P10)
5. 프로모션 코드 발급 한도·국가 조건 확인 — **미확인.** Console에서 확인한다

**대상 기준(예시 — 운영자가 정함):** 과제 4개 완료 + 설문 2회 제출

**지급 방법:**
- 설문을 제출한 **테스트 계정 이메일로 코드를 보낸다.**
- 코드 사용법 안내: Play 스토어 › 메뉴 › 결제 및 구독 › 코드 사용, 또는 앱의 PRO 화면에서 구매 창을 열어 코드 사용.

**기간에 대해:**
- `pro_lifetime`은 기한이 없는 상품이라 이 상품의 코드로 주면 **기간 제한이 없는 PRO**가 된다.
- 기간을 정해 주고 싶다면 기간제 상품(구독의 무료 체험 등)이 새로 필요하다. 지금 구조(한 번 구매)와 달라 **이번에는 권하지 않는다.**
- 어느 쪽이든 모집글에 기간을 적는 것은 운영자가 정한 뒤다.

**검증할 것(미검증):**
- 코드 사용 → 앱에서 PRO 반영
- 재설치 뒤 복원
- 코드 사용 계정과 다른 계정에서는 PRO 아님
- 서버 검사(`server-test`)에 '프로모션 구매 인정' 경우를 한 줄 추가하면 좋다. 지금은 코드 판독으로만 확인했다.

## 4. 모집글 표현(확정 전)
> 테스트를 끝까지 함께해 주신 분께는 **PRO 이용 혜택**을 드릴 예정이에요. 대상과 제공 방법은 PRO 구매가 열릴 때 따로 안내해 드려요.

- '평생 PRO'
- '무료 PRO 즉시 지급'
- 테스트 기간 중 PRO 사용 약속(테스트 빌드에서는 PRO 구매가 닫혀 있다)
