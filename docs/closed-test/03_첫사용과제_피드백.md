# 첫 사용 과제 · 피드백 문항 — DRAFT

과제 4개는 앱의 핵심 흐름(그리기 → 움직임 → 저장·다시 열기 → 내보내기)을 한 번씩 지나가게 한다. 총 20~30분이다.
각 과제에서 **걸린 시간이 아니라 '막힌 곳'**을 묻는다.

## 과제

| # | 과제 | 확인하려는 것 |
|---|---|---|
| 1 | 홈에서 **새 이모티콘**을 만들고, 01번 칸에 얼굴 하나를 그린 뒤 **저장**하세요 | 첫 진입 · 도구 찾기 · 저장의 뜻 |
| 2 | 같은 칸에서 **움직이기** 탭으로 가서 마음에 드는 움직임 하나를 넣고 세기·속도를 바꿔 보세요 | 움직임 고르기 · 조절 줄 |
| 3 | 앱을 완전히 닫았다가 다시 열어서, 01번 칸의 그림과 움직임이 그대로인지 보세요. 그다음 02번 칸을 하나 더 그려 보세요 | 저장 · 다시 열기 · 이어 그리기 |
| 4 | 보드에서 **내보내기**로 가서 파일 묶음을 만들고, 공유 창에서 원하는 곳(메일·드라이브 등)에 저장해 보세요 | 검수 화면 이해 · 내보내기 · 공유 |

## 피드백 문항 (테스트 1주차 · 2주차 끝에 같은 설문)

| # | 문항 | 형식 |
|---|---|---|
| 1 | 과제 1~4 중 막히거나 헤맨 과제가 있었나요? | 복수 선택 + '없음' |
| 2 | 막혔다면 어디서, 무엇을 찾고 있었나요? | 긴 답 |
| 3 | 그리기 화면에서 쓰기 불편했던 것(도구·브러시·조절 줄·되돌리기·확대) | 긴 답 |
| 4 | 움직임 결과가 기대와 달랐던 것 | 긴 답 |
| 5 | 캔버스 크기는 충분했나요? (쓰는 폰 기종도 함께) | 충분 / 조금 작음 / 작음 + 기종 |
| 6 | 앱이 멈추거나 꺼지거나, 그림이 사라진 적이 있나요? 있다면 언제였나요? | 예/아니오 + 긴 답 |
| 7 | 홈의 '제안까지 남은 일'이 다음에 할 일을 아는 데 도움이 됐나요? | 1~5 |
| 8 | 친구에게 이 앱을 추천할 가능성 | 0~10 |
| 9 | PRO 안내를 봤다면: 어떤 기능이 있으면 돈을 내고 쓸 것 같나요? | 긴 답(선택) |
| 10 | 그 밖에 하고 싶은 말 | 긴 답(선택) |

**버그 제보 요청:** 가능하면 폰의 **화면 녹화**나 스크린샷을 함께 보내 달라고 부탁한다. 그림 파일은 요청하지 않는다(작품은 테스터의 것이다).
