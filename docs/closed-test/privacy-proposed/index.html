1. 서비스 소개

3. 처리 목적

  • 작업 데이터·참고 이미지: 만들던 작업을 저장하고 이어서 작업하기 위해서입니다.
  • 이용권 표시: 어떤 PRO 기능을 열지 판단하기 위해서입니다.
  • 문의 메일: 문의에 답하고 문제를 해결하기 위해서입니다.
  • 결제 확인 정보: PRO 구매가 실제로 이루어졌고 아직 유효한지 Google Play 에 확인하기 위해서입니다. 앱은 스스로 "구매했다"고 판단하지 않고, 운영자 서버가 Google Play 에 조회한 결과로만 PRO 를 엽니다.

4. 기기 내부에 저장되는 데이터

  • 작업 데이터는 앱 전용 저장 공간에 저장되며, 운영체제가 다른 앱의 접근을 막습니다.
  • 운영자는 작업 데이터의 사본을 받거나 보관하지 않습니다.
  • 사진은 사용자가 사진 선택 화면에서 직접 고른 이미지만 앱 저장 공간으로 복사합니다. 사진 보관함 전체를 읽거나 목록을 만들지 않습니다. 선택·변환 과정에서 기기 캐시에 임시 파일이 남을 수 있으며, 기기의 캐시 정리나 앱 삭제로 지워집니다.
  • 기기 백업: Android 의 자동 백업 기능이 켜져 있으면 앱 저장 공간의 파일이 사용자의 Google 계정 백업에 포함될 수 있습니다. 이 백업은 Android 와 Google 계정 설정에 따라 이루어지며 운영자는 백업 내용에 접근하지 않습니다. 기기 설정에서 Google 백업을 끄면 앱 데이터도 백업되지 않습니다. 다만 이미 공유 창으로 보낸 사본(내보내기 묶음·백업 ZIP·한 칸 공유 파일)을 모아 두는 앱 안 '내보낸 파일' 자리는 Google 계정 백업에서 제외합니다.

사용자 백업과 글꼴

  • 백업 ZIP은 세트 하나(세트 관리 › 백업 파일 만들기) 또는 전체(설정 › 전체 백업 만들기: 휴지통을 뺀 모든 세트와 그림, 최근 색·내 팔레트·보관한 움직임·조각·즐겨찾기 브러시·종이 질감·사용 안내 완료 여부)로 만들 수 있습니다. 앱 안 '내보낸 파일' 자리에 만들고 사용자가 공유 창에서 고른 앱으로 보냅니다. 운영자 서버로 자동 전송하지 않습니다.
  • PRO 이용권은 백업에 넣지 않습니다. 백업 파일로는 PRO 가 열리지 않으며, 구매한 PRO 는 Google Play 의 구매 복원으로만 다시 켜집니다.
  • 되살리기는 expo-document-picker로 사용자가 직접 고른 백업 파일을 읽고 새 세트로 가져옵니다. 기존 작품을 덮어쓰지 않습니다. 전체 백업은 지금 기기의 세트·설정에 더하기만 합니다(같은 세트는 사본으로, 이미 정해 둔 설정은 그대로, 보관 칸이 찬 항목은 넣지 않고 화면에 알립니다). 파일이 손상됐으면 아무것도 바꾸지 않습니다.
  • 휴지통의 세트는 기기 안에서 30일 보관합니다.
  • 제목 글꼴 Jua는 앱에 포함된 로컬 파일이며 다운로드·전송하지 않습니다.
  • 문의하기는 메일 앱에 앱 버전·OS 버전만 미리 채웁니다. 작품·세트 이름·파일을 자동 첨부하지 않습니다. 사용자가 메일을 보내면 메일 서비스가 처리합니다.

5. 결제 관련 정보

  • 결제는 Google Play 가 처리합니다. 앱과 운영자는 카드번호 같은 결제 수단 정보를 보지 않습니다.
  • PRO 를 구매하거나, "구매 복원"을 누르거나, 앱을 실행해 기존 구매를 다시 확인할 때, 앱은 구매 토큰·상품 번호·플랫폼 세 가지만 운영자의 영수증 확인 서버로 https 로 보냅니다. 그림, 이름, 기기 식별자는 보내지 않습니다.
  • 운영자 서버는 이 정보로 Google Play 에 구매 상태를 조회하고, 확인 결과(확인 여부·이용권·확인 시각 등)만 앱에 돌려줍니다. 앱은 구매 토큰을 기기 저장 공간에 저장하지 않습니다.
  • PRO는 한 번 구매하는 비소모성 상품 pro_lifetime입니다. 결제 내역·환불 문의는 Google Play 구매 내역에서 확인합니다.

구매 비활성 비공개 테스트(EMOTICON_PURCHASES=closed)에서는 가격 조회·구매·복원·실행 시 구매 재확인 및 영수증 요청을 하지 않습니다. 정상 출시 구성은 영수증 서버 검증이 필수입니다.

7. 보관 기간

8. 삭제 방법

  • 전체 삭제: 기기 설정에서 앱 데이터를 삭제하거나 앱을 삭제하면 기기 내 데이터가 모두 지워집니다. 앱 안 '내보낸 파일' 자리의 사본(내보내기 묶음·백업 ZIP·한 칸 공유 파일)도 이 방법으로 지워집니다.
  • 내보낸 사본 정리: 설정 › 내보낸 파일에서 앱 안에 남은 사본만 골라 지울 수 있습니다(확인 후에만 지움). 세트·그림 원본과 이미 다른 앱으로 보낸 파일은 그대로입니다. 앱이 사본을 저절로 지우지는 않습니다.
