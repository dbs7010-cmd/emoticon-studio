# 사용자께 한 번에 여쭙는 것

이미 저장소·문서에서 확인되는 것은 묻지 않는다.
- 확인된 것: 앱 이름 · 패키지 · 버전 · 광고 없음 · 로그인 없음 · 수집 데이터 · 권한 · 한 번 구매 구성 · 이 PC의 키 상태
- **비밀번호나 키 파일 내용은 보내지 마세요.** 있는지와 어디에 있는지만 알려 주시면 됩니다.

## 1. Play Console 계정 · 현재 설정
1. Play 개발자 계정이 있나요? 있다면 **개인 / 조직** 중 어느 것이고, 언제쯤 만들었나요(2023년 11월 전 / 후)?
2. 본인 확인(신원 인증)이 끝났나요?
3. Console에 **'임티제작소' 앱을 만들었나요?** 만들었다면 **Play 앱 서명**(Google이 앱 서명 키 관리)을 켰나요?
4. 이 PC 밖(다른 PC·USB·클라우드)에 **이 앱용 업로드 키(.jks)**를 만들어 둔 적이 있나요? 있다면 보관 위치만 알려 주세요.
   - 이 PC에는 36차 연습용 임시 키만 있고, 그 키는 쓸 수 없습니다.

## 2. 개인정보처리방침에 들어갈 운영자 정보
5. 운영자 이름 또는 상호
6. 대표자 이름(상호와 다를 때)
7. 공개할 주소 수준(예: 시·구까지 / 사업장 주소 / 공개하지 않음 — 사업자일 때는 표시 의무가 있을 수 있음)
8. 사업자등록번호(있을 때만)
9. 시행일로 쓸 날짜
10. 방침을 올릴 곳: 가지고 있는 웹 공간이 있나요(블로그·노션·깃허브 등)?
    - 없으면 공개 페이지를 만들어 드릴 수 있으니 그렇게 알려 주세요.
11. Android 자동 백업(폰의 Google 백업에 앱 파일 포함)을 **켜 둘까요?**
    - 권장: **켜 둠.** 앱을 지웠다 다시 깔아도 작품이 돌아올 가능성이 커집니다.

## 3. 공개 문의 이메일
12. 앱 설정의 '문의하기', 스토어, 모집글에 공개할 이메일 주소
    - 개인 메일과 분리한 주소를 권장합니다.

## 4. 테스터 보상
13. 보상이 있나요?
    - 있다면: 내용(예: 기프티콘), 대상(과제 4개 완료 + 설문 2회 등), 지급 방법
    - 없다면: '자발적 참여'로 적겠습니다.
14. 모집 인원과 기간(권장: 20명 이상 · 14일 이상)
