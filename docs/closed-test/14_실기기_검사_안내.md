## 3. APK 설치(업데이트) 순서
1. APK 를 휴대전화로 옮긴다(USB·드라이브 등, 약 91MB).
2. 파일 앱에서 APK 를 누른다. 처음이면 Android 가 "이 출처의 앱 설치 허용"을 묻는다 — 운영자가 판단해 허용한다.
3. '업데이트' 또는 '설치' → 완료 후 '열기'.
4. **'앱이 설치되지 않음'이 뜨면 거기서 멈춘다**(위 2의 서명 차이). 앱을 지우고 다시 설치하지 않는다.
