## 2. 업로드 키가 정말 없을 때 — 안전한 생성·보관 절차

사람이 직접, 한 번만 한다. 클로드는 키를 만들지 않는다. 비밀번호가 클로드의 명령 기록에 남지 않게 하기 위해서다.

1. **보관 폴더를 정한다.**
   - 저장소 밖의 ASCII 경로. 예: `C:\keys\emoticon\`
   - 한글 경로는 빌드가 깨진다(36차 기록).
2. **생성**(PowerShell, 비밀번호는 프롬프트에 직접 입력):
   ```
   keytool -genkeypair -v -storetype PKCS12 -keystore C:\keys\emoticon\emoticon-upload.jks -alias emoticon-upload -keyalg RSA -keysize 2048 -validity 10000
   ```
   - 이름·조직 항목은 실제 운영자 정보로 채운다(공개 인증서에 들어간다).
3. **백업 두 곳.**
   - 암호화된 USB 하나, 개인 클라우드 보관함(암호화 압축) 하나.
   - 비밀번호는 비밀번호 관리자에만 둔다.
   - **메일·메신저·채팅·저장소에 두지 않는다.**
4. **빌드에 연결.** `C:\gradle-home\gradle.properties`(이 PC의 빌드 설정, 저장소 밖)에 네 줄을 넣는다.
   - 이름: `EMOTICON_UPLOAD_STORE_FILE` · `EMOTICON_UPLOAD_STORE_PASSWORD` · `EMOTICON_UPLOAD_KEY_ALIAS` · `EMOTICON_UPLOAD_KEY_PASSWORD`
   - 예시 파일: `release/upload-signing.example.properties`
   - 이 파일은 사용자 본인만 연다.
5. **공개 지문만 기록.** `keytool -list -v -keystore …`에서 SHA-256 지문(공개 값)을 확인해 클로드에게 알려 준다. 빌드 확인(`EMOTICON_UPLOAD_CERT_SHA256`)에만 쓴다.
6. **Play Console:** 앱을 만들 때 **Google이 생성·관리하는 앱 서명 키**(Play 앱 서명)를 고른다. 첫 AAB를 올리면 그 인증서가 업로드 키로 등록된다.

## 3. AAB 만들기 — 필요한 것과 실제 차단 원인

| 필요한 것 | 지금 | 성격 |
|---|---|---|
| 업로드 키 + 빌드 설정 네 값 | 없음 | **실제 차단(운영자)** — §2 |
| 출시 구성(`internalReview:false`) | 코드 준비됨(`release-check` PASS) | 준비 완료 |
| 서명 구조(release=업로드 키, AAB 디버그 서명 차단) | 준비됨(PASS) | 준비 완료 |
| versionCode 1 · versionName 1.0.0 · 패키지 `com.emoticonstudio.app` | 준비됨(PASS). 첫 업로드로 패키지 이름이 영구 확정 | 준비 완료 |
| 영수증 서버 주소 | 없음 → `release-check` CONFIG FAIL | **실제 차단(구조)** — 무료 테스트까지 막는다. 코덱스 지시 C7(구매를 닫은 테스트 구성)로 푼다 |
| 개인정보처리방침 URL · 문의 이메일(앱 안) | 없음 | **사용자 입력** → 코덱스 지시 C2가 빌드에 넣는다 |
| 브랜드 에셋(앱 아이콘·적응형·스플래시) | 템플릿 → ASSETS BLOCKED(종료 코드 2) | **실제 차단(에셋).** 앱 아이콘은 테스터 폰에 그대로 보인다 |
| `expo prebuild --clean` + `bundleRelease` + `release-check --aab` | 절차 문서 있음(`RELEASE_SIGNING.md` §4) | 위가 풀리면 클로드가 실행 |

**Play Console 쪽(앱 생성 후 운영자 입력):**
- 스토어 등록정보: 짧은·전체 설명(01번 초안), 앱 아이콘 512, 피처 그래픽 1024×500, 휴대전화 스크린샷(실기기)
- 개인정보처리방침 URL
- 데이터 보안 양식(코덱스 C5로 문서 갱신 후)
- 콘텐츠 등급 설문 · 대상 연령 · 광고 없음 선언 · 앱 액세스(로그인 없음)
- 비공개 테스트 트랙: 테스터 목록(이메일 또는 Google 그룹) · 피드백 채널(메일/URL) · 국가

**미확인(정책):**
