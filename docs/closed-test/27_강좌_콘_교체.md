# 27. 강좌 예시 캐릭터 → 대표 캐릭터 콘 (2026-10-16)

- 원칙: 캐릭터만 바꾸지 않고 **설명 = 실제 그림·동작**. 콘에 없는 부위(귀·꼬리·엄지)는 억지로 바꾸지 않고, 콘의 새싹 잎·손·따로 그린 소품(하트)으로 같은 기능을 보인다.
- 영상: 에뮬레이터에서 앱(검수 빌드)으로 콘을 **실제로 그리고 칠하고 움직여** 녹화(`scripts/lessons/corn-strokes.cjs` 획 좌표 = 콘 원본). 그림: 콘 원본 PNG(`scripts/mascot-render.cjs`)로 합성(`scripts/lessons/corn-art.cjs`).
- 학습 목적·무료 범위·단계 수: 그대로(무료 앱 사용법 6 · 무료 그리기 기초 3 · 작가용 1).
- 출력 확인: `scripts/lesson-corn-test.cjs` — 강좌의 세 예시를 앱 엔진으로 구움: 통통 10장 66KB · 하트만 통통 튀기 10장 67KB · 윙크 3장(0.8·0.5·0.2초) 15장 101KB, 모두 360×360 · ≤650KB · ≤24장 · 칸 밖 잘림 없음.

## 강좌 밖에서 함께 바꾼 것
- 사용 안내(첫 실행 3장, 내 정보 › 사용 안내 다시 보기) 그림 → 콘(손 흔들기 · 신나 · 끄덕 · 하트 · 수줍음)
- 스토어 그래픽 이미지(1024×500) 원본 스크립트 → 콘(업로드 파일은 운영자가 교체)
- 강좌 녹화 중 발견해 고친 것: 레이어가 여럿인 칸에서 움직임 견본에 **지금 레이어만**(하트만) 보이던 문제 · 세트 관리 창 '/32' → 세트 종류 기준
- 앱 아이콘: B안 그대로

## 남은 것
- 표현 가이드(표정 예시 20종)는 여러 캐릭터 그림 모음이라 그대로 둔다(따라 그리는 참고 그림).
- 스토어 휴대폰 스크린샷: 실기기 캡처로 다시 찍어야 한다(콘이 들어간 홈·강좌).
- 유튜브 강좌 영상(배경음악·자막 버전): 새 영상으로 다시 만들기 — `scripts/lessons/youtube.cjs`(업로드는 운영자).
