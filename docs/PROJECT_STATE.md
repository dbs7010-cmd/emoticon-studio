### CONFIRMED PROBLEMS
1. 레이어 접근이 불편하다. 큰 패널이 캔버스를 가리고 작업 흐름을 끊는다.
2. 참고 이미지 조작이 잘못되어 있다.
   - 핀치 시 참고 이미지 자체가 아니라 캔버스/전체 화면이 확대된다.
   - 참고 이미지 자체 이동은 불가능하다.
3. 대사 입력칸이 단순 텍스트 필드로 남아 있어 원래 기획인 `세트 기획 → 슬롯별 대사/참고 배치 → 연속 제작` 의미가 퇴색했다.
4. 현재 Painter가 범용 드로잉 툴처럼 보이며 `1세트 완성`이라는 제품 목적이 충분히 읽히지 않는다.
5. 홈의 프로젝트 생성 폼/카드 UI도 작업실보다 관리 폼에 가깝다.
6. 현재 visual system은 제품 정체성이 약하다.

### P0-1 REFERENCE TRANSFORM
`activeDrawLayerId`와 별도로 `activeReferenceId`를 둔다.
- 참고 썸네일 탭 → 해당 참고가 조정 대상으로 고정
- 한 손가락 = 계속 그림
- 두 손가락 이동 = 선택 참고 이미지 자체 이동
- 두 손가락 핀치 = 선택 참고 이미지 자체 확대/축소
- 참고 조정 대상이 없을 때만 캔버스 확대/이동
- 참고 ON/OFF와 조정 대상 선택을 분리

### P0-2 LAYER ACCESS
- 상단 레이어 아이콘 유지

- 그림/참고 레이어를 썸네일 + 눈 아이콘으로 즉시 확인
- 레이어 선택/표시/숨김/추가를 캔버스를 크게 가리지 않고 수행
- 현재의 큰 레이어 패널은 제거 또는 상세 설정으로 격하

### P0-3 SLOT BRIEF / SET PLANNING
Painter의 큰 대사 입력칸을 핵심 입력 UI로 사용하지 않는다.

제품 흐름:
`원캐릭터 + 참고 캡처 + 컨셉/말투 → 세트 기획 → 24/32 슬롯에 대사/무대사 + 참고 배치 → Painter 연속 제작`

Painter 상단에는 현재 슬롯의 짧은 작업 브리프만 표시한다.
예: `01 · 잘자` / `02 · 헐` / `03 · 무대사`.
- 탭하면 빠른 수정 가능
- AI 대사 추천은 Painter가 아니라 세트 기획 단계
- 참고 포즈/구도는 텍스트 설명보다 배정된 실제 참고 이미지가 주 가이드
