## CURRENT — DEVICE FEEDBACK ROUND 4 / USABILITY
다음 항목은 P0 마감 전에 함께 고려한다. 아직 LOCKED 세부 UI는 아니며, 실기기 사용성을 기준으로 최소 변경한다.

1. **세트 삭제 기능**
   - `내 작업실` 프로젝트 카드에서 세트 삭제가 가능해야 한다.
   - 오동작 방지를 위해 카드의 `…` 또는 관리 메뉴 안에 둔다.
   - 즉시 삭제 금지: 세트명/진행률을 보여주는 확인 절차 후 삭제한다.
   - 한 세트의 슬롯/로컬 이미지/작업 데이터가 함께 정리되는지 검증해야 한다.

2. **불투명도 조절 접근성 개선**
   - 현재 참고 이미지 불투명도 Slider 로직은 존재하지만 상세 패널 안에 있어 접근성이 낮다.
   - 선택된 참고 이미지에는 빠른 불투명도 조절이 필요하다.
   - 그림 레이어 불투명도도 같은 개념으로 확장할지 UX를 통일해서 결정한다.
   - 초보자에게 `opacity` 같은 용어 대신 `진하게 / 연하게` 또는 `불투명도`처럼 바로 이해되는 한국어를 사용한다.

3. **펜 / 지우개 / 굵기 배치 개선**
   - 현재 펜·지우개 선택과 굵기 `-/+`가 서로 떨어져 있어 도구와 속성의 관계가 약하다.
   - 선택한 도구 바로 옆 또는 한 덩어리 안에서 굵기를 조절할 수 있게 재배치한다.
   - 지우개 선택 시 같은 위치의 굵기 컨트롤이 `지우개 크기`로 즉시 바뀌어야 한다.
   - 화면 높이를 잡아먹지 않도록 별도 복잡한 설정 패널은 만들지 않는다.

4. **초보자용 레이어 UX 재설계**
   - 현재 `그림 1/2`, `참고`, 보임/숨김, 선택 상태가 한 레일 안에서 섞여 초보자에게 개념적으로 어렵다.
   - 기능을 줄이는 게 아니라 용어와 구조를 단순화한다.
   - 기본 화면에서는 `내 그림`과 `따라 그릴 참고` 두 그룹만 먼저 이해되게 한다.
   - `레이어`라는 전문 용어는 상단에서 바로 강요하지 않고, 필요 시 `그림 겹치기` 또는 `레이어` 보조 표기로 검토한다.
   - 고급 변형/불투명도/보임숨김은 선택 항목을 눌렀을 때만 노출한다.
   - Infinite Painter처럼 빠르게 접근되되, 그 앱의 전문 사용자 전제를 그대로 가져오지 않는다.

5. **현재 목표 유지**
   - Painter를 범용 드로잉 앱처럼 키우지 않는다.
   - 핵심은 `참고를 깔고 → 쉽게 따라 그리고 → 저장 → 다음 칸`의 반복 속도다.
   - 기능 추가가 이 리듬을 느리게 만들면 기본 화면에서 숨기거나 후순위로 보낸다.
