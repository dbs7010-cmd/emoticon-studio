## CURRENT — UX / PRODUCT INTENT RECOVERY
실기기 2차 피드백 기준. 현재 화면은 아직 `상업 이모티콘 세트 제작 앱`보다 `간단한 Painter`로 보인다. 다음 수정은 기능 추가보다 제품 의도를 UI와 작업 흐름에 되살리는 것이 우선이다.

### CONFIRMED PROBLEMS
1. 레이어 접근이 불편하다. 큰 패널이 캔버스를 가리고 작업 흐름을 끊는다.
2. 참고 이미지 조작이 잘못되어 있다.
   - 핀치 시 참고 이미지 자체가 아니라 캔버스/전체 화면이 확대된다.
   - 참고 이미지 자체 이동은 불가능하다.
3. 대사 입력칸이 단순 텍스트 필드로 남아 있어 원래 기획인 `세트 기획 → 슬롯별 대사/참고 배치 → 연속 제작` 의미가 퇴색했다.
4. 현재 Painter가 범용 드로잉 툴처럼 보이며 `1세트 완성`이라는 제품 목적이 충분히 읽히지 않는다.
5. 홈의 프로젝트 생성 폼/카드 UI도 작업실보다 관리 폼에 가깝다.

### REFERENCE DESIGN DIRECTION — INTERACTION ONLY
사용자가 주로 쓰던 Infinite Painter 스크린샷을 작업성 레퍼런스로 사용한다. 시각 스타일을 복제하지 않고 다음 상호작용 원칙만 참고한다.
- 캔버스가 화면의 주인공이어야 한다.
- 주요 도구는 작고 즉시 접근 가능해야 한다.
- 레이어는 상단 아이콘 → 좁은 우측 플로팅 레이어 스택 형태가 적합하다.
- 큰 모달/설정 패널이 그림을 장시간 가리지 않는다.
- 프로젝트 화면은 폼보다 썸네일 중심 작업실/프로젝트 그리드가 적합하다.
- 색감/테마는 추가 레퍼런스를 받은 뒤 결정하며 현재 LOCK하지 않는다.

Painter의 큰 대사 입력칸을 핵심 입력 UI로 사용하지 않는다.
원래 제품 흐름을 복원한다.

`프로젝트 시작 → 원캐릭터 + 레퍼런스 + 컨셉/말투 → 세트 기획 → 24/32 슬롯에 대사/무대사 + 참고 배치 → Painter 연속 제작`

Painter 상단에는 현재 슬롯의 `작업 브리프`만 작게 표시한다.
예: `01 · 잘자` / `02 · 헐` / `03 · 무대사`
- 탭하면 빠른 수정 가능
- AI 대사 추천은 Painter 안의 큰 버튼이 아니라 세트 기획 단계에서 수행
- 참고 포즈/구도는 텍스트 설명보다 배정된 실제 참고 이미지가 주 가이드

### P0-4 PRODUCT UI

- SET BOARD: 4열 슬롯 보드 + 원캐릭터 + 진행률. 관리 메뉴는 `…`로 숨김.
