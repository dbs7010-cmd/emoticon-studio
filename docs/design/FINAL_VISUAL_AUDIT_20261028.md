# 출시 전 비주얼 점검 · 2026-10-28

판정: 승인된 비주얼 적용·에셋 전달을 마쳤다. 출시 빌드 승인과 해외판 완역 승인은 별도다.

## 적용한 방향

캐릭터는 귀엽게, 작업 도구는 차분하게. 홈은 emoti 글자와 큰 표지, 강좌는 16:9 썸네일과 아래 제목으로 정리했다. 점토 그림자와 큰 입체 테두리를 줄이고, 노랑은 주요 행동, 보라는 선택 상태에 사용했다. 삭제 요청한 MY COLLECTION 소개 블록과 표지 위 이어 그리기 버튼은 넣지 않았다. 공지 진입은 유지한다.

App 전용 `app-ui.tsx`가 기존 `ui.tsx`와 분리되어 캔버스 내부 공통 부품을 바꾸지 않는다. 기존 저장·결제·로그인·엔진 서비스와 버전 설정을 수정하지 않았다.

## 검증 근거와 한계

- 캔버스·움직이기·애니메이션·기존 공통 UI·타입·앱 설정 8개 파일이 기준 HEAD와 바이트 단위로 동일하다. `verification/visual-direction-v24/canvas-unchanged.json` 참조.
- Android Hermes 번들 생성 통과. `export-android-final.log`와 `bundle-android/metadata.json` 참조. APK/AAB 또는 서명·설치 검사가 아니다.
- 최신 소스 대체 렌더 29종을 생성했다. 390×844dp 기준이며 일부 HTML 전체 길이 캡처는 스크롤 내용을 함께 보여 준다. 기기가 비정상적으로 길다는 뜻이 아니며 실제 기기 캡처도 아니다.
- 전체 자동 검사 최종 결과는 `npm-test-final.log`에서 확인한다. Native/WebView 대역 검사와 실제 Chrome 엔진 검사 범위를 각 PASS 메시지에 명시한다.
- 저장 검사 실패는 엔진을 수정한 것이 아니라, 검사가 찾던 예전 `bitmap()` 구간을 실제 `docCanvas()` 구간으로 맞춰 해결했다. 참고 레이어 제외 단언을 유지했다.
- Android export에서 기존 iOS 광고 App ID 미설정 경고가 나온다. 이번 작업은 Android 번들 대상이며 iOS 출시 준비 완료로 보고하지 않는다.

## 언어 점검

기존 53개 문구를 검토하고 ko/ja/zh-Hant를 305개 키로 확장했다. 언어별 키와 자리표시자 동등성, 주요 강좌 제목의 번역, 강좌 ID·단계 수·행동 보존을 검사했다. 잘못된 일본어/한자 작가명 예시는 실제 입력 규칙에서 허용하는 Mochi01로 수정했다.

일부 PRO 상세·동적 안내·강좌 핵심 정리·규격 안내·래스터 썸네일의 한국어와 캔버스 문구가 남아 있다. 강좌/가이드 런타임 감사만으로도 일본어·번체 각각 45개 미번역 문자열을 확인했다. `i18n-coverage.json`은 이를 숨기지 않고 목록으로 제공한다. 사람 원어민 검수는 하지 않았으며 해외판 완역 상태가 아니다.

## Claude 인계

1. 기능 작업과 이 비주얼 소스를 합치고 이전 승인 아이콘을 연결한다.
2. 한국어 새 빌드에서 폰·폴드·태블릿, 글자 확대, 실제 저장/재실행, 로그인·결제·복원, 강좌 영상 재생을 확인한다.
3. 캔버스 내부 디자인 변경 없이 현재 조절툴과 흰 영역을 보존한다.

5. APK/AAB·서명·versionCode·출시 검사·실제 스토어 스크린샷을 생성한다. Codex가 최종 빌드나 스토어 업로드를 한 것으로 간주하지 않는다.
