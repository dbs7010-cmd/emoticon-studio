## 39차 캡처에서 본 것
- Painter(`12-caption-direct`, `07-canvas-size-drag`): 캔버스 아래 **빈 회색 띠(약 130dp)** 가 도구 줄과 캔버스 사이에 있어 캔버스가 떠 보이지 않고 공중에 흩어져 보임 → 캔버스 영역 바탕을 따뜻한 중립으로, 도구 dock 을 표면으로.
- Motion(`13-motion-통통`): 네 카드가 같은 크기라 "없음"이 기본 선택처럼 강함. 카드 안 견본이 너무 작아(44px) 움직임이 잘 안 읽힘.
- Board(`16-board`): 칸 아래 "완성"/"작업 중" 알약이 칸마다 붙어 격자보다 글자가 먼저 보임.
- Home(`03-home`): 세트 두 장 아래 큰 빈 공간, 새 세트 버튼이 흐린 회색이라 첫 행동으로 안 보임.
- Export(`17-export-fail`, `now2`): 흰 카드가 연달아 쌓여 검사 페이지처럼 보임.
