# 임티제작소 — 이미지 생성 AI 전달 문서 (ASSET GENERATION HANDOFF, 41차)

이 문서 하나만 읽고 제작에 들어갈 수 있게 쓴다. 규격 숫자의 원본은 `docs/design/ASSET_PRODUCTION_SPEC.md`(에셋별 표)이며, 둘이 다르면 그 문서가 맞다.
**지금 발주 범위는 PHASE 1(메인 캐릭터 CANON 후보 9안)뿐이다.** 다른 에셋은 CANON LOCK 뒤에 같은 문서로 발주한다.

---

## 1. 제품
- 이름: **임티제작소** (Android 앱)
- 한 문장: 스마트폰과 손가락만으로 이모티콘을 그리고, 움직임을 붙이고, 카카오 이모티콘 제안용 한 세트(멈춰있는 32개 / 움직이는 24개)를 파일 묶음까지 완성하는 **창작 도구**.
- 사용자: 전문 그림 앱·태블릿 경험이 적은 **한국 성인**(대략 20~40대) 창작자. 아이가 아니다.
- 앱이 약속하지 않는 것: 승인·판매·수익. 카카오 공식 앱이 아니다.

## 2. 브랜드 인상
| 되고 싶은 것 | 피하는 것 |
|---|---|
| 친근하지만 장난감 같지 않은 | 어린이 그림 앱 |
| 조용히 장난스러운(quirky) | 과한 귀여움(overly kawaii) |
| 따뜻한 오프화이트 작업실 | 무지개 파스텔 |
| 손으로 그린 느낌이 살짝 남은 | 3D 광택 기업 마스코트 |
| 상용 앱처럼 다듬어진 | 흔한 AI 마스코트 · 스톡 일러스트 |
| 성인 창작자가 돈 내고 쓸 만한 도구 | 포토샵 축소판 같은 차가운 전문가 툴 |

키워드: `warm off-white` · `restrained yellow` · `clean adult creator tool` · `slightly hand-drawn` · `quirky but not childish` · `friendly but not toy-like` · `commercially polished`

## 3. 앱 시각 언어(40차 실제 UI — 그림이 여기에 얹힌다)
| 토큰 | 값 | 그림에서의 뜻 |
|---|---|---|
| 앱 바탕 | `#FAF8F2` | 그림이 가장 자주 놓이는 바탕 |
| 흰 표면 | `#FFFFFF` | 카드 |
| 따뜻한 표면 | `#FFF9E8` (가장자리 `#F4E6B8`) | 홈 창작 표면 · 완성 요약 · PRO 비교 |
| 보조 표면 | `#F5F3ED` | 빈 칸 · 목록 썸네일 바탕 |
| 강조 노랑 | `#FFD02F` (옅은 `#FFF2B6`) | **작은 포인트로만**(펜 끝·별 하나·볼터치). 캐릭터 몸 전체를 노랗게 칠하지 않는다 |
| 글자·선 | `#171717` / 노랑 위 `#20242C` | 캐릭터 외곽선 기준색 |
| 보조 글자 | `#66635D` · `#99958C` | 그림자·질감 톤 참고 |
| 선 | `#E9E6DE` · `#DAD5CA` | — |
| 성공 / 주의 / 위험 | `#2F8A57` / `#A86400` / `#B3403A` | 그림에 거의 쓰지 않음 |

- UI 는 둥근 모서리(8~24), 옅은 그림자, 테두리 1px, 노랑은 한 화면에 한두 곳이다. 그림이 UI 보다 시끄러우면 실패다.
- 캔버스·사용자의 그림이 주인공인 앱이다. 브랜드 그림은 **사용자 그림보다 "더 잘 그린" 인상을 주지 않는다**(기존 원칙).

## 4. 절대 금지
- 그림 안에 **한국어·영어 문장, 라벨, 숫자, "PRO", 버튼 모양** 넣기(모든 글자는 앱이 그린다)
- 카카오·카카오프렌즈 캐릭터·로고·노랑 말풍선 구성 따라 하기, 다른 브랜드 로고
- 3D 렌더·광택·글로우·강한 그라데이션·네온
- 무지개 파스텔 팔레트, 에셋마다 다른 색감
- 에셋마다 다른 선 두께·다른 머리 비율·다른 눈 모양(캐릭터 불일치)
- 아기 같은 비율의 과한 볼·반짝이 눈·하트 남발
- 스톡 일러스트 풍 사람 손·배경 소품 과다
- 배경 풍경(투명 규칙이 있는 에셋에 바닥 그림자 외 배경 그리기)

## 6. PHASE 1 발주 — 메인 캐릭터 CANON 후보 9안
캐릭터 3종 × 방향 3개. 각 안은 **같은 조건**으로 만든다: 정면 전신 1장 + 3/4 전신 1장 + 표정 3(기본·기쁨·억울), 투명 PNG 2048×2048, 가운데 80% 안, 바닥선 90%, 글자 없음.

| 방향 | 목표 | 바꿔도 되는 것 | 지켜야 하는 것 |
|---|---|---|---|
| ① 원형 최대보존형 | 사용자가 그린 원본을 거의 그대로, 가장자리·선만 정리 | 선 흔들림 정리, 질감 밀도, 명암 한 단계로 | 몸 모양·비율·눈·팔다리·소품 전부 |
| ② 앱용 정제형 | 40차 UI(따뜻한 오프화이트·절제된 노랑) 위에서 작게(41~112dp)도 읽히게 | 질감 줄임, 실루엣 단순화, 선 두께 통일, 노랑 포인트 하나 추가 | 캐릭터 정체성(종이/잉크/지우개임이 즉시 보임), 점 눈 |
| ③ 강한 브랜드형 | 앱 아이콘·피처 그래픽까지 버틸 상징성 | 머리(몸) 비율 확대, 팔다리 약간 두껍게, 한 가지 대표 포즈 | 원본 소재·절제된 표정, 금지 목록 |

비교 판정 기준(사용자가 고른다): 112dp·44dp 로 줄였을 때 알아볼 수 있는가 / #FAF8F2·#FFF9E8 위에서 튀지 않고 살아 보이는가 / 어린이 앱처럼 보이지 않는가 / 세 캐릭터가 한 가족처럼 보이는 확장성.

## 7. 선·색·질감 규칙(CANON 이후 모든 에셋 공통)
- 외곽선: **한 가지 두께**, 색 `#171717` 계열(순검정 금지 아님 — 먹 캐릭터는 몸 자체가 검정). 2048px 마스터 기준 약 10~12px, 표시 크기가 달라도 에셋 간 **상대 두께가 같게**(작은 에셋에서 선만 두꺼워지면 안 됨 → 작은 에셋은 형태를 단순화).
- 채색: 평면 채색 + 그림자 **한 단계**(`#66635D` 15~20% 느낌), 빛 방향 왼쪽 위 고정, 하이라이트·광택 없음.
- 질감: 종이 결·연필 문지름은 **아주 옅게**, 작은 에셋(≤ 48dp)에서는 없앤다.
- 노랑 `#FFD02F`: 한 그림에 한 곳 이하, 전체 면적 8% 이하.
- 바닥 그림자: 옅은 타원 하나(선택), 투명 에셋의 유일한 "배경".

## 10. 일관성·CANON 규칙
1. PHASE 1 에서 사용자가 고른 안 = **CANON**. 턴어라운드 시트(정면·3/4·옆·뒤, 표정 6, 대표 포즈 4)를 만들고 파일 해시를 `ASSET_PRODUCTION_SPEC.md` 에 기록한다.
2. 이후 모든 캐릭터 에셋은 **CANON 시트를 참조 이미지로 넣고** 만든다. 머리/몸 비율, 눈 모양·간격, 선 두께, 소품, 색 값이 시트와 다르면 불합격.
3. CANON 을 바꾸고 싶으면 새 버전(CANON v2)으로 다시 승인받고, 이미 만든 에셋은 전부 다시 만든다. 에셋마다 조금씩 "개선"하지 않는다.
4. 조연(BR-02·03)은 CANON 의 선·그림자·눈 문법을 그대로 따른다.
5. 마네킹(RF)은 캐릭터가 아니다 — CANON 의 비율과만 호환, 표정·소품·색 없음.

## 11. 전달 형식
- 파일 이름: `docs/design/ASSET_PRODUCTION_SPEC.md` 의 Implementation path 이름 그대로(예: `home-hero.png`, `home-hero@2x.png`, `home-hero@3x.png`).
- PHASE 1 산출물 이름: `canon-candidate-{paper|ink|eraser}-{1|2|3}-{front|3q|face-default|face-happy|face-upset}.png`
- 색 공간 sRGB, 8-bit PNG(RGBA), 메타데이터 제거.
- 한 번에 넘기는 묶음마다 1장짜리 비교 시트(`#FAF8F2` 바탕, 112dp·44dp 축소 미리보기 포함)를 같이 준다.
