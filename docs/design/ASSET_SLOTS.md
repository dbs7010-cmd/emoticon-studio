# 임티제작소 에셋 자리 규격 — 44차 FINAL LOCK

> 44차(PRE-ASSET UI/UX LOCK)에서 실제 최종 UI 기준으로 다시 확정했다. 제작 발주 전체 명세는 `docs/design/ASSET_PRODUCTION_SPEC.md`, 생성 AI 전달은 `docs/design/ASSET_GENERATION_HANDOFF.md`. 이 표가 앱 안 자리의 원본 요약이다.

코드 원본: `src/design/asset-slots.ts` (`ASSET_SLOTS`). 화면은 `AssetSlot` 컴포넌트(`src/components/ui.tsx`)로 그린다 — `size` 는 **폭**, 높이 = 폭 ÷ 비율.
에셋이 없으면 같은 크기의 따뜻한 도형 자리표시가 그려진다. **에셋을 넣을 때는 `source` 만 `require(...)` 로 바꾸고, 비율이 다른 그림을 넣지 않는다.** 그림이 안 맞으면 그림을 고친다 — UI 는 다시 뜯지 않는다.

공통: 앱 안 그림은 투명 PNG `@1x/@2x/@3x`(S24 Ultra 는 @3x). 마스터는 표시 크기 8배 이상. **한국어 글자·숫자·PRO 표시는 그림에 넣지 않는다**(앱이 그린다). 기준 폭 360 · 384(S24) · 412dp.

### 44차에 없앤 자리
- 캔버스 위 표현 가이드 한 줄 힌트(`ExpressionHint`)와 그 보조 그림(옛 CR-02 `expressionGuideVisual`) — 가이드는 홈의 '표현 가이드' 화면으로 옮겼고 캔버스 위에는 아무것도 띄우지 않는다.
- 옛 레퍼런스 가로 줄 64×85 — 4열 격자로 바뀌었다(비율 3:4 는 그대로).
- 전체 작업 화면 전용 그림: **만들지 않는다**(세트 5개 이상일 때만 들어가는 목록 — 빈 상태가 없다. 목록 썸네일은 사용자의 실제 칸 그림).

## 기능 자리
- `EXPRESSION_GUIDE = { ready: false, categories: 기쁨·인사 · 슬픔·미안 · 화남·억울 · 놀람·당황 · 일상, cards: 20 }` — 카드 = 그림 자리 + 표현 이름(≤6자) + 몸짓 힌트(≤14자). 누를 수 없는 둘러보기 카드. 글자는 앱.
- `BUILTIN_REFERENCES = { enabled: true, ready: false, categories: 포즈·표정·손동작·소품·효과, placeholderCount: 8, columns: 4 }` — 분류 칩 한 줄 + 격자(패널 안 세로 스크롤, 최대 높이 min(260, 캔버스 가림 한도 − 110)). 고른 칸은 옅은 노랑 표면(에셋 라운드). 그림이 없는 분류는 "이 분류에는 아직 그림이 없어요" 한 줄. 누르면 기존 참고 사진과 같은 흐름(옮기기·크기·진하기)으로 캔버스 참고 레이어.
- `HOME_NOTICE.enabled = false` — 켜면 표현 가이드 줄 아래·최근 작업 위에 카드 하나.

## 그림 톤
- 2~2.5등신 짤뚱한 캐릭터·관절 인형. 손그림 선. 사용자의 그림보다 "더 잘 그린" 인상을 주지 않는다.
- 노랑(#FFD02F)은 작은 포인트로만. 카카오 캐릭터·로고·색 조합을 따라 하지 않는다.
