# PRODUCT UX RESET — 설계 (38차, 2026-09-15)

근거: 37차 뒤 PRODUCT UX DESTRUCTION AUDIT 의 P0 11건 · P1 전체. 엔진(캔버스·Undo·레이어·움직임·내보내기)과 저장 형식은 그대로 둔다.
사용자가 보는 구조만 다시 짠다.

## 핵심 흐름
홈 → 새 세트 → (바로) 첫 칸 그리기 → 필요하면 움직이기 탭 → 완성 · 다음 → … → 보드에서 결과 확인 → 내보내기

## 결정

### 1. 도구 모델
- 도구 줄: **브러시 · 지우개 · 채우기 · 선택 · 색**. "펜"은 더 이상 도구 이름이 아니다 — 브러시 안의 선 종류(펜·붓·연필) 이름이다.
- 한 번 누르면 선택, **이미 고른 도구를 다시 누르면 그 도구의 설정**(브러시 → 브러시 시트, 지우개 → 지우개 크기). 설정이 있는 도구는 선택 상태에서 작은 위쪽 화살표로 표시한다.
- "펜 · 6 ^" 칩과 "펜 설정" 시트는 없앤다.

### 2. 잠금
- 작업 도구에서 잠금은 **한 줄**만: 무료 브러시 시트의 "고급 브러시 · PRO" 입구 하나.
- 진하기, 선 보정 약·중·강, 스포이드, 내 팔레트 저장, RGB·투명도는 **무료**로 돌린다. 다른 드로잉 앱에서 기본으로 기대하는 기능이고, 잠가서 PRO 가치를 만들지 않는다(완성은 무료).
- PRO = 생산성과 고급 표현: 부분 움직임·두 모습 번갈아·차례로, **여러 칸에 같은 움직임 한 번에**, 고급 브러시 4종.
- PRO 는 **시작 전에** 알린다. 무료 사용자는 부분 움직임·일괄 적용 입구를 누르면 바로 PRO 안내로 간다. 만들고 나서 저장할 때 막는 흐름은 없앤다(저장 시 확인은 만료 사용자를 위한 안전장치로만 남긴다).

### 3. 입구 하나씩
| 기능 | 대표 입구 | 없앤 입구 |
|---|---|---|
| 참고(따라 그릴 사진) + 캐릭터 기준 | 탭 줄 "참고" | 떠 있는 "참고 열기", 캔버스 위 기준 그림 썸네일, ⋯ 기준 그림 보기/기준으로, "기획" |
| 문구 | 탭 줄 "문구"(입력·위치 조절 모두) | ⋯ 문구 넣기, 아래 "문구" 칩 |
| 움직이기 | 탭 "움직이기" | 아래 "움직이기" 버튼 |
| 이전 칸 그림 | 빈 칸: 캔버스 위 "이전 칸 그림으로 시작" / 그린 칸: ⋯ | (동시에 둘이 보이지 않음) |
| 규격 안내 | 내보내기 › 자세히 | 설정·세트 메뉴의 규격 알림 |
| 칸 순서 | 세트 메뉴 | 보드 위 버튼 줄 |

"기준 그림"은 **캐릭터 기준**으로, 레이어 기본 이름 "그림 N"은 화면에서 **레이어 N**으로 부른다(저장된 이름은 바꾸지 않는다).

### 4. 저장
- 저장 버튼 없음. 작업은 자동저장(주기·앱 내리기·칸 이동·닫기·완성).
- 사용자가 하는 확정은 **완성 · 다음** 하나. 움직이기 탭에서도 같은 자리, 같은 버튼.
- 움직임은 고르는 즉시 캔버스에 적용되고 칸과 함께 저장된다. "취소/적용" 없음. "없음" 카드로 뺀다.

### 5. 24컷
- 브러시 선 종류·굵기·지우개 크기는 세트(project.brush)에 남아 다음 칸·재시작에도 유지. 도구 선택은 앱을 켠 동안 유지(선택 도구 제외).
- 빈 칸을 열면 이전 칸 그림으로 시작하는 카드를 한 번 보여 준다. 누를 때만 복사(확인창 없음 — 비어 있는 칸이라 잃을 것이 없고 되돌리기 가능).

### 6. 움직이기
- 미리보기 우선: 움직이기 탭에서는 캔버스를 위로 붙이고 패널은 캔버스 아래 남는 자리를 쓴다.
- 효과 카드는 내 그림이 **그 효과대로 실제로 움직이는 견본**. 가짜 재생 막대·반복 길이·크게 보기 줄 제거.
- 속도·세기는 효과를 고른 뒤에만. 문구 스위치는 문구가 있을 때만.
- 부분 움직임(PRO 사용자): 카드는 접힌 상태 → 펼치면 효과·양·속도 → "세부 조절"을 눌러야 중심점·시작/끝·방향. 재생 순서는 부분이 둘 이상일 때만. 두 모습 번갈아는 별도 화면.

### 7. 보드
- 격자가 먼저. 위에는 완성 개수 한 줄과 전체 재생 아이콘만.
- 아래 고정 줄: 남은 칸이 있으면 **이어서 그리기**(노랑), 완성이 하나라도 있으면 **내보내기**(회색). 다 채우면 내보내기가 노랑.
- 일괄 적용은 움직이는 칸이 생긴 뒤 세트 메뉴에만.

### 8. 내보내기
1) 결과 격자 2) 손볼 곳 3) 필요한 부가 이미지 4) **파일 묶음 만들기** 5) 자세히(규격·밝은/어두운 바탕·직접 확인·파일 검사)
- 약속 문구 통일: 무료로 "파일 묶음으로 내보내기"까지. "제출 파일"이라는 말은 앱 어디에도 쓰지 않는다. 움직이는 칸은 카카오 WebPAnimator 에서 마무리한다는 사실은 한 줄로 남긴다(가이드 규칙).

### 9. 문구·개발자 흔적
- 나쁜 UI를 설명하던 문장은 UI를 고치고 지운다(선택 "이동은 끌어서…", 문구 색 안내, 두 모습 안내, 대표 이미지 안내, 사람 판단 안내, 저장 사본 안내, 첫 사용 제스처 안내).
- 오류 원문·revision·JSON 단계·파일 앞뒤 글자·"저장 상태 보기" 제거. 복구 화면은 할 일(다시 불러오기)과 문의용 사본 보내기만.
- 글자 기호(‹ ⋯ ↶ ↷ ☰ ▶ ＋ ×)는 MaterialCommunityIcons 로.
