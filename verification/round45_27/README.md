## 3. C 의 구체적 목표 (구현 지시로 쓸 수 있게)

**도구 순서와 위치** (위에서 아래로)
1. 머리줄 52dp — `<` · `그리기` · 되돌리기 · 다시 실행 · `완료`(노랑, 36dp)
2. 참고 영역 — **있을 때만**. 접힘 44dp / 펼침 약 140dp
3. 캔버스 — 남은 높이에 정사각(`min(폭, 남은 높이)`)
4. 브러시 카드 3종 — 74dp, 항상 보임
5. 색 + 굵기 한 줄 — 44dp (색 ● 28dp · `굵기` · 막대 · 숫자)
6. 도구 줄 — 64dp, 펜/지우개/채우기/선택 네 칸 균등

**기본 노출 / 펼침 상태**
- 기본: 1·3·4·5·6 만 보인다. 판은 하나도 열려 있지 않다.
- 브러시 카드는 **늘 보인다**. 눌러도 판이 열리지 않는다.
- 세부 설정(진하기·선 보정·고급 브러시)은 카드 줄 오른쪽 작은 입구로 **펼쳤을 때만** 자리를 차지한다.
- 색은 5번 줄의 동그라미를 눌러 연다. 한 번에 한 판만 열린다.

**선택 · 닫기 · 캔버스 복귀**
- 브러시 카드: 누르면 그 브러시로 바뀌고 **아무 판도 열리지 않는다**(이미 보이므로).
- 색 판 · 세부 설정: 머리 오른쪽 48dp 닫기, 바깥(캔버스) 한 번 터치로도 닫힌다. **닫는 첫 터치는 획을 만들지 않는다.**
- 판이 닫히면 캔버스는 원래 자리·크기로 돌아온다(패널은 덮어 뜨고 캔버스를 밀지 않는다).

**참고 영역과 판이 차지하는 공간**
- 참고 영역은 캔버스 **밖**이라 캔버스를 줄인다(그래서 가리지 않는다).
- 색 판·세부 설정은 캔버스 **위에 덮어** 뜨고 캔버스를 45% 넘게 가리지 않는다.
- 참고와 판을 함께 열면: 머리줄 + 참고(접힘 44) + 캔버스 + 카드 + 한 줄 + 도구 줄 + 덮는 판. 640dp 높이에서도 캔버스 한 변 ≥ 280dp 를 지킨다.

**좁은 화면(320dp)**
- 브러시 카드 3종은 그대로 세 칸(카드 폭이 줄어든다). 글자는 줄이지 않는다.
- 색+굵기 한 줄에서 `굵기` 글자를 떼고 막대를 늘린다(숫자는 남긴다).
- 도구 줄 네 칸은 그대로. 아이콘 위 글자를 유지한다.
- 머리줄이 넘치면 되돌리기·다시 실행을 둘째 줄로 내린다(글자·손가락 자리는 줄이지 않는다).
