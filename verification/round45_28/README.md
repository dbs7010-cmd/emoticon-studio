## 1. UI 구현

### 1-1. 상단 — 되돌리기 · 다시 실행 · 완성

- 머리줄이 `< 세트이름 01/32 · ↶ ↷ [완성 →] · ···` 이 됐다. **완성은 노랑**이고, 누르면 예전과 같은
  `save('complete')` 를 부른다 — 완성 표시 · 저장 · 다음 칸 이동이 그대로다(새 경로를 만들지 않았다).
- **하단의 큰 완성 줄을 없앴다.** 움직이기 탭이 자기 완성 버튼을 따로 갖고 있어 화면에 둘이 있었다
  (`motion-panel.tsx` 의 아래 줄과 그 세 prop 을 삭제). 이제 어느 탭에서도 완성은 머리줄 하나다 —
  `viewport-matrix-test` 가 20가지 화면 크기에서 '완성 후 다음'이 **정확히 하나**임을 못 박는다.
- 중복 되돌리기도 없다. 쓰지 않게 된 `UndoButton` 은 지웠다.
- 폭이 좁으면 **글자나 손가락 자리를 줄이지 않고** 명령 묶음만 둘째 줄로 내린다
  (`cmdStacked` — 실제 배치 폭을 재서 가른다. 320dp·글자 배율 1.5 에서도 같은 규칙).

### 1-2. 기능 진입점 — 움직이기 · 참고 · 레이어 · 문구

머리줄 아래 보조 줄에 `그리기 | 움직이기` 와 `참고 · 레이어 · 문구` 가 그대로 선다. 아무것도
더보기로 옮기거나 없애지 않았다. 세트·칸 정체성(01/32, 세트 이름)도 그대로다.

### 1-3. 브러시 — 무료 4 + PRO 8

| 묶음 | 브러시 |
|---|---|
| 기본(무료) | 펜 · 연필 · 붓 · 마커 |
| PRO | 매끈한 잉크 · 부드러운 펜 · 결 연필 · 캘리그래피 · 크레용 · 에어브러시 · 납작펜 · 거친 선 |

- **캔버스 아래 빠른 카드 셋이 늘 보인다.** 처음은 펜 · 연필 · 마커. 카드마다 그 브러시의 **실제 엔진
  획**(`assets/art/stroke-*.png`, 12장 전부 `scripts/_strokes.cjs` 가 엔진을 띄워 그은 것)과 이름이 들어간다.
- 카드를 누르면 **고르기**, 고른 카드를 다시 누르면 **세부 설정**이 열린다.
- `전체` → 무료 4 + PRO 8 을 한 판에. 거기서 고르면 **빠른 줄의 한 자리를 차지하고 판이 닫힌다.**
  빠른 줄은 판이 열려 있는 동안에도 그대로 보인다.
- 고르지 않은 카드를 흐리게 죽이지 않는다. 흐린 것은 **PRO 인데 아직 이용권이 없는 것**뿐이고,
  그 이유는 묶음 머리에 한 번만 적는다(`PRO · 이용권이 있으면 열려요`). 자물쇠 아이콘은 하나도 없다.
- 무료 사용자가 잠긴 브러시를 누르면 **캔버스를 건드리지 않고** PRO 안내로 간다
  (`color-test`: 누르기 전후 `brushSettings` 명령 수가 같다).
- 엔진에 프리셋 5종을 **더했다**(캘리그래피·크레용·에어브러시·납작펜·거친 선). 기존 4종
  (ink·soft·grain·marker)은 손대지 않았다 — 저장된 작품의 외형이 바뀌지 않는다.

### 1-4. 굵기 · 색 · 하단 도구

- 브러시 카드 **아래 한 줄**: `● 현재 색` · `굵기` · 가로 슬라이더 · 숫자. **세로 조절대는 없앴다**
  (45.25 의 세로 조절대 지시를 45.28 지시가 대체). 중복은 없다 — 굵기를 조절하는 곳은 화면에 하나뿐이고,
  `viewport-matrix-test` 가 20가지 크기에서 그것을 확인한다.
- 굵기는 **그리거나 지울 때만** 보인다. 채우기·선택·글씨 손질·스포이드 중에는 칸만 남기고 비운다
  (줄 높이가 흔들리지 않게).
- 현재 색 버튼을 누르면 색 패널이 열린다. 패널은 **SV 사각(가로 = 선명함 · 세로 = 밝기) + 색상 막대**로
  열린다. 밝기 막대는 없앴다 — 사각의 세로축이 같은 값이라 두 곳에서 같은 것을 조절하지 않게 했다.
  최근 색 · 내 팔레트 · 색 추출 · 색 저장 · HEX · 투명도는 그대로고, 기본 색 견본 격자는 `팔레트` 갈래에 있다.
- 하단 **도구 네 칸 균등**: 펜 · 지우개 · 채우기 · 선택(각 `flex:1`, 48dp).
- **활성 도구와 열린 설정 판을 다르게 말한다**: 노랑 표면은 '지금 그리는 도구' 하나뿐이고,
  열린 판(색·브러시 전체)은 **테두리**로 말한다. `visual-system-test` 가 '도구 줄의 노랑은 한 곳뿐',
  '빠른 줄의 노랑도 한 장뿐', '색을 열어도 노랑이 되지 않는다'를 못 박는다.
- 승인 보드는 카드와 도구 줄 둘 다 '펜'이라 적는다. **보이는 글자는 보드대로 두고**, 읽어 주는 이름만
  `그리기 도구 펜`으로 갈랐다 — 화면은 보드와 같고, 스크린 리더에서는 둘이 구분된다.

### 1-5. 참고와 작업 공간

- 참고는 캔버스 **밖** 전용 자리에 그대로 있다. 제목·힌트·밑그림 버튼은 한 곳뿐이다.
- 캔버스는 정사각이고 논리 좌표를 유지한다(엔진에 손대지 않았다).
- 작은 화면에서 설정은 **스스로 구르고**, 고정 도구 줄·닫기 버튼을 밀거나 겹치지 않는다.
  이번에 실제로 한 곳이 깨져 있었다 — 브러시 판이 시트의 스크롤 **안에 또** 스크롤로 들어가면서
  아래 고정 줄(세부 설정)이 화면 밖으로 밀려나 있었다. 시트에 `plain` 을 두어 한 겹만 구르게 고쳤다.
  `screens-320/draw-brush-detail.png` 가 고친 뒤 모습이다.

### 1-6. 손가락 자리

현재 색 버튼은 보이는 크기 32 이지만 hitSlop 8 로 **48×48** 이다(줄의 좌우 여백이 그만큼 있어 이웃과

## 3. 결제 — 비소모성 일회성 PRO

| 항목 | 이전 | 지금 |
|---|---|---|
| 상품 | `pro_monthly` · `pro_yearly`(구독) | **`pro_lifetime` 하나 · 비소모성 일회성** |
| 요청 | `type:'subs'` + offer token | `type:'in-app'`, offer 없음 |
| 확정 | `isConsumable:false` | 같음 — 소비 처리하지 않는다 |
| 서버 | `purchases.subscriptionsv2` | `purchases.products`(상품 id + 토큰) |
| 이용권 | 기간 있음 | `plan:'lifetime'`, **기한 없음** |
| 해지 | 구독 관리 | 해지 없음 — 스토어 **구매 내역**으로 |

- **14,900원은 후보 가격이다.** 화면은 스토어 가격이 오기 전까지 `후보 가격 · 미확정` 과
  "아직 확정된 판매가가 아니에요"를 함께 적는다. 어디에도 최종 판매가로 못 박은 곳이 없다.
- **예전 구독을 가진 사람의 권한을 버리지 않는다**: 저장된 `monthly`·`yearly`, 스토어에 남은 구독,
  서버의 구독 판정 규칙을 모두 남겼다. 둘 다 있으면 기한 없는 일회성 PRO 가 먼저 복원된다.
- **내부 검수 PRO 와 실제 구매 권한은 여전히 분리돼 있다.** 검수용 해제는 `reviewUnlock` 이고
  `Entitlement` 안에 들어가지 않는다. 출시 구성에서는 `internalReviewBuild()` 가 거짓이라 효력이 없고
  화면에 그려지지도 않는다(`review-pro-test`).

### 외부 차단 — 코드로 풀 수 없는 것

| 막힌 것 | 필요한 것 | 상태 |
