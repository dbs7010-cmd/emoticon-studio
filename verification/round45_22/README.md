## B. 조사해서 **바꾸지 않은** 것

| 항목 | 확인 결과 |
|---|---|
| `완성 · 다음` 이름 | `save('complete')` → `saveFinal(..., complete)` 이 `done:true` 로 **표시하고 저장한 뒤 이동**한다. 빈 캔버스면 스스로 `stay` 로 낮춘다. **이름이 정직하므로 그대로 둔다**(§E10 이 요구한 조사). |
| 가이드 → 프로젝트 선택 | 가장 최근 세트의 다음 빈 칸을 연다. 세트가 없으면 새로 만들고, 다 찼으면 보드를 보여 준다. **덮어쓰기·자동 생성으로 바꾸지 않았다.** |
| 새 칸 레이어 수 | 1장. HTML 시안의 '레이어 2' 는 시안 수치다. |
| 참고의 출력 제외 | 엔진 `save`·`buildLoop` 가 `layers` 만 합친다. **정책 그대로.** |
| 자동저장·token·1.5초·20초 | 45.12·45.13 정책 그대로. |
| 저장 schema·ID·PRO·가격 | 손대지 않았다. |
