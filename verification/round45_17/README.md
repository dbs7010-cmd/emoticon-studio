## A. 무엇을 만들었나

> 표현 가이드는 창작자의 내비게이션이다. 하나의 감정에서 다양한 표정·자세·구도를 제시하고 자기 캐릭터로 응용하도록 돕는다.

흐름: **감정 선택 → 다양한 표현 보기 → 예시 선택 → ① 참고하며 그리기 / ② 밑그림으로 넣기.**
이번에는 `고마워` 다섯 갈래로 전체 흐름을 이었다. 다른 19개 감정과 기본 레퍼런스 32칸은 **건드리지 않았다.**

## D. 참고 창 — 화면 위의 안내이지 그림이 아니다

- 손잡이(위쪽 띠)에서만 끌린다. 그림 자리를 눌러도 창이 따라가지 않는다.
- 머무는 자리는 캔버스 영역 안으로 **맞춰 준다**. 오른쪽·아래로 끝까지 끌어도 창 전체가 화면 안에 남고, 왼쪽·위는 가장자리 8dp 에서 멈춘다.
- 창은 `pointerEvents` 를 비우지 않는다 → **창이 덮은 자리에서는 캔버스가 손가락을 받지 않는다.** 옮기는 손이 선을 긋지 않는다.
- 접기(손잡이 줄만 남음) · 다시 펼치기 · 닫기. 닫아도 고른 예시는 그 칸에 남아 **참고 줄의 '표현 예시' 칸에서 다시 연다.**
- 창은 React Native 겹침 화면이라 캔버스 엔진 밖에 있다 → **작품·썸네일·출력 어디에도 들어가지 않는다.**

## E. 밑그림 — 기존 참고 레이어를 그대로 썼다

새 저장 구조를 만들지 않았다. 조사해 보니 참고 레이어 길이 이미 필요한 것을 전부 갖고 있었다.

1. 번들 그림 → `importBundledImage` → 세트의 `referenceImages` 에 합류(`mergeImages`, 참고 사진 추가와 같은 함수).
2. `addReferences` 로 캔버스에 넣는다 — `id: 'ref-<파일>'`, `opacity: .3`, `visible: false`, `x/y 0 · scale 1 · rotation 0`.
3. `toggleReference` 로 켠다 — 참고 타일을 누를 때와 같은 명령이라 **'한 번에 하나만 보인다'** 는 기존 규칙이 그대로 지켜진다.

그래서 저절로 따라오는 것들:

| 요구 | 어디서 오는가 |
|---|---|
| 비율 유지 · 중앙 배치 | 엔진 `loadLayer` 의 `min(W/w, H/h)` 축소와 가운데 정렬 |
| 기본 진하기 30% | 참고 레이어의 기존 기본값 |
| 위치·크기·진하기·숨김·삭제 | 참고 줄의 기존 조절(캔버스에서 끌기·핀치, 진하기 막대, 눈 아이콘, 참고 관리 › 삭제) |
| 별도 그림 레이어에 그리기 | `references` 와 `layers` 가 애초에 다른 배열이다. 손이 가는 곳은 여전히 `draw-1` |
| 기존 그림·문구·부분 움직임 보존 | `addReferences` 는 `checkpoint()` 뒤 참고만 밀어 넣는다. 레이어를 만들거나 지우지 않는다 |
| 최종 PNG·움직이는 파일 제외 | 엔진 `save` 와 `buildLoop` 가 `layers` 만 합친다(`references.forEach` 없음) |
| 작품 썸네일 제외 | 썸네일은 저장된 완성 그림(`finalImage`/`motionImage`)을 쓴다 |
| 저장·복원 | `savePainterWork` 가 `referenceImages` 에서 경로로 되찾는다 — 밑그림도 같은 자리에 있으므로 같은 길로 저장되고 되살아난다 |
