### 썸네일과 캔버스용 원본의 관계
| | 썸네일 | 캔버스용 원본 |
|---|---|---|
| 쓰이는 곳 | 참고 패널 4열 격자 칸 | 고른 뒤 캔버스에 깔리는 참고 레이어 |
| 크기 | 권장 192×255, 화면에서 78×104 ~ 91×121dp | 권장 1080×1440 |
| 비율 | **3:4 고정** | **3:4 고정**(같아야 한다) |
| 맞춤 | `cover` — **3:4 가 아니면 가장자리가 잘린다** | 캔버스 360×360 안에 비율 유지로 축소(`min(W/w, H/h)`), 가운데 정렬 |
| 바탕 | 불투명 허용 | **투명 필수**(그림 위에 겹쳐 깔린다) |
| 진하기 | 그대로 | 기본 30%, 사용자가 조절 |
| 관계 | **같은 그림의 두 용도.** 썸네일은 원본에서 줄여 만들되 비율이 어긋나면 격자에서 본 것과 캔버스에 깔리는 것이 달라진다 | |

**코드 공백**: 목록 구조(분류별 배열)와 `pickBuiltinReference`·`movePose` 에서 참고 레이어를 넣고 바꾸는 부분이 비어 있다(주석만 있다). 그림만으로는 켤 수 없다.

## 3. PRO 전·후 비교 — 실제 움직임으로 보여 주는 최소안 (구현하지 않음)
정지 그림 교체안은 **후보로 유지하고 확정하지 않는다.**

| 항목 | 내용 |
|---|---|
| 재사용할 코드 | `MotionSample`(`src/painter/motion-panel.tsx:42`) — 통통·흔들기·두근거리기를 `transform`(translateY / rotate / scale)으로 돌린다. 타이머 하나로 한 컴포넌트만 다시 그린다. 새 엔진 필요 없음 |
| 필요한 최소 그림 | **PNG 2장**: ① 몸(움직이지 않는 부분) ② 움직일 부분(예: 팔 한쪽). 둘 다 1:1 · 투명 · 같은 캔버스 기준으로 그려 겹치면 한 캐릭터가 되게. 왼쪽(전체 움직임)은 두 장을 겹친 채 **함께** 움직이고, 오른쪽(부분 움직임)은 **② 만** 움직인다 |
| 수정할 컴포넌트 | ① `motion-panel.tsx` — `MotionSample` 옆에 층 두 장을 받는 작은 변형 하나(애니메이션 수식은 그대로 쓰고 `transform` 을 어느 층에 걸지만 다르게). ② `App.tsx` PRO 시트의 비교 블록(정지 `<Image>` 두 개를 이 컴포넌트로 교체). ③ `src/design/asset-slots.ts` — 자리 정의가 지금은 `source`/`sourceAfter`(전·후 두 장)라서 **몸·부분 두 층**을 담도록 뜻을 바꾸거나 자리를 새로 정해야 한다 |
| 실제 기능과 일치하는가 | **부분 움직임의 핵심(한 층만 움직인다)은 그대로다.** 다만 실제 기능은 중심점 지정 · 여러 부분 · 시작 간격 · 두 모습 교대까지 되고, 예시는 그중 한 부분 한 효과만 보여 준다. **기능보다 더 화려하게 꾸미지 않는다**는 선에서 축소된 표현이며, 왼쪽에 쓰는 효과는 무료 효과 셋 중 하나여야 말과 그림이 어긋나지 않는다 |
| 추천 | 새 엔진을 만들지 않는 이 방식(그림 2장 + 컴포넌트 두 곳 수정)이 최소안이다. 다만 **자리 정의를 바꾸는 결정**이 필요하므로 사용자 확정 뒤에 착수한다 |
