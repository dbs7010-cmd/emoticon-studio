### B. 아이콘 통일성
- **라이브러리는 한 가지다.** MaterialCommunityIcons, 120곳.
- **스타일이 섞여 있다.**
  - 채움 아이콘: `fountain-pen-tip`, `eraser`, `format-color-fill`, `star-four-points`, `pencil`, `draw`, `check-circle`
  - 선 아이콘: `image-outline`, `layers-outline`, `motion-play-outline`, `eye-outline`
  - 글자 아이콘: `format-text`
  - 같은 도구 줄에 이 셋이 나란히 선다(`painter.tsx:401` 도구, 모드 줄의 참고·레이어·문구).
- **크기가 15가지(12~40)다.** 18(38곳) · 20(24곳) · 16(14곳) · 22 · 14 · 19 · 15 · 17 ….
  - 역할별 규칙이 없다. 예: 모드 줄 보조 17, 도구 20~21, 캔버스 안내 14~16.
- **의미가 겹치거나 추상적이다.**
  - 움직임 '없음'이 `motion-pause-outline`(재생 정지처럼 읽힘, `motion-panel.tsx:225`)
  - 로고가 `draw` 한 개
  - 되돌리기 `undo-variant`
- **선택 표시를 아이콘이 아니라 배경 면이 전부 맡는다.** 아이콘 자체는 선택돼도 같다.

**원칙:**
1. **작품이 가장 화려하다.** UI는 흰색과 중립색이고, 색은 사용자가 그린 이모티콘에서 나온다(홈 카드의 작품 네 칸이 화면에서 가장 색이 많다).
2. **노랑은 한 화면에 한 곳이 주인공이다.** 예: 홈의 '15번 칸' 버튼, 보드의 '지금 칸'.
3. **검정 2px 테두리는 '누를 노란 버튼'과 '지금 고른 것'에만 쓴다**(45.39 절충안 유지).
4. **밋밋하지 않게 하는 장치:**
   - 작품 썸네일
   - 칸 단위 진행(칸 막대·칸 격자)
   - 두들 캐릭터 한 장
   - 제목 글꼴 Jua
   - 흰 바탕 위 옅은 그림자 한 층
5. **어린이 앱처럼 보이지 않게:** 파스텔 면 남발 금지, 둥근 모서리 14~22 한 벌, 글자는 짧고 성인 말투.

## 7. 정제 1회 (사용자 지시 반영, 제품 미반영) — `proto2/`

**사용자 결정:**
- White Base 승인
- 「임티 라인」 방향 승인
- 32칸 진행·짙은 완료 카드는 LOCK 전

| 항목 | 정제 전(5번 줄) | 정제 후(6번 줄 · `proto2/`) |
|---|---|---|
| 색 | 노랑 + 초록 + 보라가 동시에 브랜드처럼 보임 | **WHITE / INK / NEUTRAL / MAKER YELLOW.** 초록은 저장 성공 체크 한 곳에만. 보라 없음 |
| PRO | 보라 칩·보라 면 | 잉크 테두리 배지 + 반짝 아이콘 + 전/후 구성(선택 쪽 잉크 테두리) |
| 아이콘 선택 | 모든 아이콘에 노란 방울 | **노란 면 + 잉크 아이콘.** 방울 없음 |
| 브랜드 디테일 | 전부 | '손그림 한 획'은 펜·문구·움직이기 세 개만 |
| 시스템 아이콘 | 없음 | 뒤로·닫기·삭제·보임·숨김·되돌리기·더 보기·확인·설정: 보편 모양 그대로 같은 선 1.8. 선택 대신 누름(옅은 회색 면) |
| 움직이기 아이콘 | 원 + 가로줄(읽히지 않음) → 원 + 호 | 튀어 오르는 공 + 바닥선 + 튐 자국 |
| 홈 카드 | 32칸 막대 하나 | **A(32칸 막대) / B(18/32 + 막대 + 다음 칸)**를 같은 크기(350×230)로 비교 |
| 홈 구성 | 새로 시작 두 칸 | '이어서 만들기' 카드(노란 이어 그리기) + '새 세트 만들기'(잉크 테두리) 두 행동이 위에. '내 그림으로 시작'은 아래 한 줄 |
| 완료 | 짙은 카드 하나 | **A(짙은 카드) / B(흰 카드 + 작품 32칸 + 노란 체크 튀어 오름)** |

**추천:**
- **홈 카드는 B.** 홈의 일은 '이어서 / 새로'다. 진행은 숫자 하나 + 막대 하나 + 다음 칸으로 충분하다. 32칸 막대(A)는 **세트 보드**의 머리에 두면 칸 격자와 함께 의미가 산다.
- **완료는 B.** 짙은 면은 앱 전체에서 여기 한 곳뿐이라 다른 앱처럼 보인다. 흰 카드에서도 작품 32칸 + 노란 체크 튀어 오름 + 노란 CTA로 '다 했다'가 충분히 보인다.
- **아이콘:**
  - 선택 = 노란 면 + 잉크(도구 줄은 + 잉크 2px)로 확정 권장.
  - 움직이기 아이콘은 실기기 크기(22)에서 한 번 더 확인이 필요하다.
