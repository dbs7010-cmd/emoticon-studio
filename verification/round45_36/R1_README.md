## 2. 레이아웃 판단 — 캔버스를 위에 붙였다

시안은 캔버스가 모드 줄 바로 아래에 선다. 45.35~45.36 은 그리기 탭만 **가운데** 정렬이라 정사각 캔버스 위아래로 빈 띠가 갈렸고,
조절대는 그 빈 띠 옆까지 뻗었다. 이제 두 탭 모두 **맨 위**에서 시작하고 남는 자리는 아래 한 덩어리다.

- 캔버스는 늘이거나 자르지 않았다(360×360 논리 캔버스 그대로).
- 판(색·레이어·참고)이 그 빈자리로 열려 그림을 덜 가린다: 390×1000 에서 색 판이 캔버스를 가리는 비율 **0**.
- 그리기 ↔ 움직이기 전환 때 캔버스 위치가 같다.

## 3. G11 — 견본과 엔진을 나눠 적는다

**이번에 한 것(견본 입력만):**

| 브러시 | 설명(`use`) | 견본 입력 |
|---|---|---|
| 테이퍼 펜 `ink` | 시작이 가늘어지는 선 | 짧은 획 셋 — 끝이 여섯 번 보인다 |
| 붓펜 `brushpen2` | 천천히 그으면 굵어지는 붓 선 | 한 획: 앞 절반 느림(24ms 간격) → 뒤 절반 빠름(8ms) · 굵기 15 |
| 납작 펜 `flat` | 팁 각도에 따라 굵기가 달라지는 선 | 방향이 자주 바뀌는 물결 |
| 불투명 채색붓 `opaque` | 겹쳐도 얼룩 없는 고른 면 | 두 번째 획을 길게(짧으면 뭉툭한 조각처럼 보였다) |

견본 생성 페이지에서만 `Date.now` 를 가상 시계로, `Math.random` 을 고정 씨앗 난수로 바꿨다. **엔진 코드는 한 글자도 바꾸지 않았다.**
결과: 같은 입력이면 같은 견본(두 번 구워 30/30 해시 동일). 처음 비교 때 두 번째 실행이 끝나기 전에 비교해 "38/38 동일"로 잘못 본 적이 있다 — 끝난 뒤 다시 비교해 분필·드라이 잉크 2종이 달랐고, `Math.random` 을 고정해 해결했다.

**엔진 미감 라운드로 넘기는 것(엔진 결함 — 견본으로 감추지 않는다):**

| 브러시 | 무엇 | 보드 위치 |
|---|---|---|
| 납작 펜 `flat` | 획 **시작점에 큰 둥근 덩어리**. 첫 점에 방향이 없어 납작 팁 대신 원을 찍는 것으로 보인다 | 5번 |
| 붓펜 `brushpen2` | 시작점에 작은 혹 | 4번 |
| 테이퍼 펜 `ink` | 테이퍼 길이가 캔버스 18px 고정 — 긴 획에서는 끝만 살짝 가늘다 | 3번 |
| 기본 펜 · 거친 잉크 · 붓결 잉크 | 행 크기에서 서로 비슷하다 | 1·11·13번 |
| (45.34 부터) 색연필 겹침 · 자연 잉크 잔물결 · 작은 글자 테이퍼 · 연필 옆면 | 미해결 | — |
