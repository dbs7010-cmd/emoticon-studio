# 45.8 — 실기기 대체 증거 (2026-09-21)

실기기(SM-S928N)는 이번 라운드에서 **연결 불가**(무선 디버깅 포트 거부 — 사용자 외출 중), 이 PC의 에뮬레이터 이미지는 **arm64 전용이라 x86_64 호스트에서 실행 불가**(`Avd's CPU Architecture 'arm64' is not supported ... on x86_64 host`).
그래서 두 가지 증거만 수집했다. **RN 화면(홈·도크·패널)의 픽셀 캡처는 BLOCKED.**

## 1. 실제 픽셀 증거 — 그리기 엔진 (`shots/*.png`)

앱이 WebView 에 넣는 **바로 그 캔버스 엔진 HTML**(`engine.html`, `src/painter/canvas-html.ts` 에서 추출)을 로컬 서버로 띄워 같은 명령으로 그린 결과다.
그림 엔진 부분은 기기와 같은 코드다. 다만 **글꼴은 이 PC 의 것**이라 글씨체 비교는 기기와 다를 수 있다.

| 파일 | 내용 |
|---|---|
| `E1-brush-pen-brush-pencil.png` | 같은 색·8px 로 펜(위)·붓(가운데)·연필(아래) |
| `E2-brush-18px.png` | 같은 비교를 18px 로 |
| `E3-caption-basic/serif/thick.png` | 같은 문구 '안녕하세요' 를 글씨체 셋으로 |
| `E4-motion-rest.png` · `E4-motion-peak.png` | 통통 움직임 정지/최고점(11px 올라감) |

측정값(엔진에서 직접 잰 수치):

- 18px 획: 붓 6,481px(펜 대비 +41% 면적) · 펜 4,584px · 연필 4,571px(반투명 픽셀 20%, 펜 8%)
- 글씨 폭(이 PC): 기본 200.0 · 도톰 200.0 · 또박 193.2 → **기본과 도톰의 글자 자체는 같고, 흰 테두리 두께만 다르다**
- 글자 픽셀: 기본 2,569 · 도톰 2,569 · 또박 1,992
- 통통 재생: 잉크 맨 위 y 71 → 60~55 (11~16px 실제 이동)

## 2. 구조 증거 — RN 화면 (`STRUCTURE.md`)

실제 화면 코드를 렌더해 **상태별로 보이는 조작을 차례대로** 뽑았다(픽셀 아님).
순서·이름·상대 크기·선택 상태는 사실이고, 색감·여백·손맛은 이 표로 알 수 없다.
막대(굵기·속도·세기 같은 adjustable)는 버튼이 아니라 표에 나오지 않는다.

## 3. BLOCKED (이번 라운드에서 만들 수 없던 것)

홈·전체 작업·그리기 화면·브러시/색/문구/레이어/움직이기 패널의 **실제 스크린샷**, 키보드가 올라온 상태, 연속 3칸 제작 캡처.
→ 기기 연결 또는 x86_64 에뮬레이터 이미지(약 1.5GB 내려받기, 사용자 승인 필요) 가 있어야 한다.
