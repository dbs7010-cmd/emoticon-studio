# 화면별 디자인 검토 자료 — 390dp

`index.html` 을 열면 19개 화면이 한눈에 서고, 각 화면은 PNG 와 HTML 로 따로 있다.

만든 법: `node scripts/_screens.cjs` (실제 App 을 그려 HTML 로 옮김) → `node scripts/_shots.cjs <포트>` (그 HTML 을 브라우저에서 PNG 로 굳힘).

ZIP 으로 받았다면 **폴더째 풀고** `index.html` 을 연다. `assets/` 안의 그림과 화면별 PNG 를 함께 참조하므로 index 한 장만 있으면 아무것도 보이지 않는다.

## 이 자료의 성격 — 반드시 먼저 읽을 것

**대체 렌더다. 실기기 캡처가 아니다.**

- 소스를 실제로 그려(`react-test-renderer`) 나온 **노드와 스타일을 그대로 옮긴 것**이다. 따로 꾸민 시안이 아니다.
- **그림은 실제 번들 PNG 다.** 정적 `require` 를 원본 파일로 풀어 `assets/` 로 복사해 붙였다. 19개 화면에서 못 붙인 그림 0장.
- **캔버스 안도 실제 엔진이 그렸다.** `src/painter/canvas-html.ts` 에 앱과 같은 `init → save` 를 보내 받은 합성 PNG(`assets/canvas-sample.png`)다. 따로 그린 가짜 캔버스가 아니다.
- 그래서 **판정할 수 있는 것**: 배치·순서·간격·글자 크기와 굵기·색·모서리·상자 구조·그림이 실제로 어떻게 앉는지.
- **판정할 수 없는 것**:
  - 기기에서 사용자가 직접 그린 그림 — 칸 그림은 `greeting-thanks-polite.png` 한 장을 넣어 흉내 낸 것이다.
  - 그리기 중의 캔버스 — 시험 그림 한 장이고, 손으로 긋는 획·확대·제스처는 기기가 한다.
  - 글꼴 메트릭·줄바꿈 — 안드로이드 글꼴이 아니라 이 컴퓨터의 글꼴로 그렸다.
  - 실제 스크롤 잘림 — 스크롤 영역을 펼쳐 그렸다. 길이는 기기에서 달라질 수 있다.
  - 아이콘 — 앱과 같은 집합(Material Design Icons)이지만 웹폰트로 그렸다.
  - 실제 터치 — 손가락 자리는 배치 계산으로만 확인했다(`../touch-layout.txt`).
