## 1. 브러시 실제 획 — **내 보고가 틀렸다. 엔진은 정상이다**

45.25 에 '붓이 펜과 같은 확정 획을 낸다'고 적었다. **그 보고가 틀렸다.**

원인은 엔진이 아니라 **견본을 만들던 쪽**이었다. 엔진의 `window.command` 는 약속(Promise)으로 줄을 세워 명령을 처리하는데, 생성기가 그것을 기다리지 않고 바로 획을 그었다. 그래서 매 획이 **앞 브러시 설정으로** 그어졌고 결과가 한 칸씩 밀렸다(펜 → 펜, 붓 → 펜, 연필 → 붓).

기다리게 고치고 **입력 중 → 확정 후 → 저장·재열기 후** 세 단계를 모두 재 봤다(`scripts/_brush-pipeline.cjs`, 같은 곡선 · 굵기 14 · 같은 색):

| 브러시 | 단계 | 굵기(3곳) | 최대 알파 | 잉크 픽셀 |
|---|---|---|---|---|
| 펜 | 입력 중 / 확정 후 / 재열기 후 | 21 / 18 / 27 | 255 | 6877 |
| 붓 | 입력 중 / 확정 후 / 재열기 후 | 29 / 25 / 37 | 255 | 9538 |
| 연필 | 입력 중 / 확정 후 / 재열기 후 | 21 / 18 / 27 | 140 | 6859 |

- **세 단계가 모두 같다** — 저장·재열기가 외형을 바꾸지 않는다. 기존 저장 작품도 그대로다.
- 붓은 펜의 **1.38배** 굵다(소스의 `penWidth × 1.4` 가 그대로 산다).
- 연필은 굵기가 같고 **알파 140**(소스의 `0.55` 가 그대로 산다).

**엔진은 고칠 것이 없어 손대지 않았다.** 소스의 `×1.4 · 알파 0.85` 를 정답으로 밀어 넣지 않고 먼저 확인한 결과다.

획 견본 셋은 바로잡힌 생성기로 다시 만들었고(`scripts/_strokes.cjs`), `asset-contract-test` 가 '셋이 서로 다르다'를 못 박는다 — 같은 실수를 다시 못 한다.

증거: `brush-pipeline.png`(행 = 펜·붓·연필, 열 = 입력 중·확정 후·재열기 후) · `brush-pipeline.txt` · `brush-pipeline.json`

## 4. 표시용 이미지 — 63장 전수 확인

`fill-sheet.png` 에 **63쌍 전부**(왼쪽 원본 · 오른쪽 표시용, 파스텔 바탕)를 모아 훑었다. 더해서 채운 자리를 덩어리로 나눠 재어(`scripts/_fill-audit.cjs`) 의심스러운 35장을 뽑고, 그중 **12장은 크게 놓고 다시 봤다**(`fill-suspects-1~3.png`).

**결과: 원래 비어 있어야 할 곳이 희게 찬 것은 없었다.**

- 덩어리가 여럿인 것은 머리·손·소품처럼 **따로 닫힌 자리**였고 모두 채워야 맞는 곳이었다.
- 팔과 몸 사이, 다리 사이, 소품 바깥은 바깥과 이어져 있어 채워지지 않았다 — 파스텔이 그대로 보인다.
- 눈물·속도선·`z` 같은 작은 장식은 채우지 않는다(닫혀 있지 않거나 너무 작다).

**완료로 처리하지 않는 것**(그대로 남는다):

1. **미생성 18장** — 선이 끊겨 흰색이 샐 수 있어 만들지 않았다. 이 중 **감정 대표 5장**(괜찮아? · 흥 · 짜증나 · 당황 · 설마)이 있어, 그 다섯은 감정 목록에서 여전히 바탕색이 몸으로 비친다.

```
angry-angry-face          angry-annoyed-ears        angry-annoyed-facepalm
angry-annoyed-head        angry-annoyed-sigh        angry-hmph-pout
angry-hmph-turn           daily-good-night-drowsy   sad-are-you-okay-chest

surprise-flustered-glance surprise-flustered-sweat  surprise-gasp-face

```

2. **가장자리 미충전** — 그림이 이미지 가장자리에 닿으면 그 부분은 닫힌 자리가 아니라 채워지지 않는다(`daily-good-night-blanket` 의 이불).

원본과 밑그림 파일은 그대로다. 표시용은 `assets/expression-guides/display/` 에만 있고, 캔버스에 깔리는 것은 여전히 원본이다.

## 5. 새 그리기 레이어 · PRO — 유지 확인

이미 있던 흐름은 그대로 두고, **부분 성공이 없는지 그 경로만** 검사로 못 박았다:

- 그림 장이 **네 장이면**: 밑그림은 들어가고 빈 장은 만들지 않으며, 왜 못 만드는지 한 번 말한다. 기존 그림을 지우거나 덮어쓰지 않는다.
- 넣기 자체가 **실패하면**: 참고도 빈 장도 남지 않고 한 번만 알린다.

검수용 PRO 는 `review-pro-test` 가 그대로 지킨다 — 내부 빌드에서만 보이고, 토글 ↔ 부분 움직임 · 고급 브러시 진입이 함께 열리고 함께 잠긴다. 출시 구성에는 그려지지 않는다.
