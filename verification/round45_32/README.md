## 1. 브러시별 문제 → 수정 → 결과 → 남은 한계

문제는 **장면으로 보고** 찾았다(얼굴 외곽선·손글씨·채색·질감·효과). 원인을 항목에 연결해

### 엔진 전체에 걸린 수정 (여러 브러시의 공통 원인)

| 문제 | 원인 | 수정 | 결과 |
|---|---|---|---|
| 작은 원·급회전에서 **톱니(톱날)** | 납작한 dab 이 진행 방향에 직각으로 눕는데, 도는 반지름이 dab 보다 작으면 양 끝이 바깥으로 삐져나온다 | 도는 반지름 R ≈ 간 거리 / 바뀐 각 을 재서 `R < 2r` 이면 납작함을 버리고 둥글게 눕힌다 | 마커의 눈·ㅇ 이 원으로 나온다. 연필 옆면·오일 파스텔의 꺾임도 깨끗 |
| 획 **끝 뭉침** | 손을 대는 순간 방향을 모르는 채 가로로 누운 dab 을 찍었다 | 첫 자국을 없애고, **움직이지 않고 뗀** 손가락에만 둥근 점 하나 | 끝에 방향이 어긋난 자국이 남지 않는다 |
| 보정이 셀 때 획 끝의 **곧은 꼬리** | 남은 거리를 한 번에 직선으로 이었다 | 네 걸음에 나눠 따라붙인다 | 끝이 곡선을 따라 마무리된다 |
| 작은 굵기에서 **선이 끊겨 보임** | 옅고 무른 dab 이 서로 닿지 않는다 | 반지름 4px 아래로 갈수록 단단하고 진하게 보정 | 굵기 4px 에서도 '안녕!' 이 읽힌다(`sheet-small.png`) |
| 굵기가 변하는 선의 **단 지기** | 선분마다 굵기를 바꿔 이어 그었다 | **띠(ribbon) 합성** — 양쪽 가장자리를 따로 잇고 한 번에 채운다. 끝은 둥글게 마감 | 테이퍼·붓펜·자연 잉크의 굵기가 매끄럽게 이어지고 바늘 끝이 없다 |

### 의도된 거친 결 vs 렌더링 결함

고친 것은 **렌더링 결함**뿐이다 — 톱니, 끝 뭉침, 곧은 꼬리, 작은 크기 끊김, 굵기 단 지기,
구멍 뚫기, 줄무늬. 크레용의 덩어리·목탄의 큰 결·드라이 평붓의 끊김·스프레이의 흩뿌림처럼
**재료가 원래 거친 것은 그대로 두었다.** 모든 브러시를 매끈하게 만들지 않았다.

## 4. 저장 호환 · 출력 · 성능

### 저장 호환

| 무엇 | 확인 |
|---|---|

| 구형 ID | `marker` · `brushpen` · `base:pencil` · `soft` · `grain` · `calligraphy` · `chisel` · `base:brush` 모두 엔진과 저장 형식에 그대로 |

### 입력 경로

짧은 획 · 긴 획 · 급회전 · 느린 입력 · 빠른 입력을 확인했다. 손가락 경로(압력 없음)를 기준으로
보되 **펜 압력 입력 경로는 그대로 남겨 두었다**(`computeBrushWidth`/`computeBrushAlpha`).
속도 반응은 손가락에서 압력을 대신하는 것이고, 압력이 오면 압력이 함께 쓰인다.
