- **저장 버튼의 동작**: 지금은 누르면 이 칸을 완성으로 표시·저장하고 **다음 칸으로 넘어간다**(예전 '완성'과 같다). 이름이 '저장'이 된 만큼, 누른 뒤 그 칸에 머무르게 할지.
