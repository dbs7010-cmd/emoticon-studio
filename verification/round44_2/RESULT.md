Painter 굵기 UI와 확대 칩·색 패널은 지시대로 **건드리지 않았다**.

## 1. Reference 흐름 (찾기 → 선택 → 격자 퇴장 → 캔버스에서 맞추기)
- 4열 격자·분류 넷(포즈·표정·손동작·소품·효과)·3:4 썸네일 그대로.
- 칸을 누르면 격자가 접히고, 그 자리에 한 줄이 남는다: "캔버스에서 위치·크기·진하기를 맞춰요" + **다시 찾기** 버튼.
- 참고 탭을 다시 열거나 세그먼트를 바꾸면 격자가 다시 열린다(`refBrowse`).
- 자리표시(에셋 전)에서도 칸이 눌리므로 흐름 전체가 지금 동작한다. `BUILTIN_REFERENCES.ready=true` 가 되면 같은 자리에서 기존 참고 레이어 흐름으로 넘긴다(`pickBuiltinReference`).
- 한 줄 캐러셀로 줄이지 않았고 격자 크기도 그대로다.

## 2. Guide → Painter
- 표현 카드가 버튼이 됐다. 누르면:
  - 세트가 있으면 **가장 최근 세트의 다음 작업 칸**으로 기존 흐름 그대로 들어간다(`nextUnfinished`).
  - 세트가 없으면 기존 `createNewProject()` 로 새 세트를 만든다. 새 생성 시스템은 만들지 않았다.
- Painter 로 넘어가는 것은 **표현 이름 + 짧은 몸짓 힌트 한 줄뿐**이다(`guideHint` prop). 저장 구조(Project/Slot)는 건드리지 않았다.
- Painter 에서는 캔버스 위 빈 띠에 한 줄 힌트로만 보이고, **첫 획을 그으면 사라지며**(`scene.dirty`) X 로 즉시 닫을 수 있다. 칸을 닫으면 힌트 상태도 지워진다. 새 패널·새 저장 상태 없음.

## 3. Motion 빈 칸 미리보기
- `hasDrawing = finalImage || work || dirty || undo`.
  - 그림이 있으면 **사용자 그림이 언제나 먼저**(저장본 또는 지금 레이어 썸네일).
  - 아무것도 없으면 견본 그림(`motionExampleArtwork` 자리, 지금은 `mascot-paper`)이 대신 움직인다.
- 효과 로직·엔진은 건드리지 않았다.

## 4. Home / 전체 작업
- 구조 그대로(최근 4 + 전체 보기, 전체 작업 한 줄 목록). 새 관리 기능 없음.
