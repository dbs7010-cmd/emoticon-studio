## 2. 원형 도장 연결 흔적 — 의도한 질감이 아니라 결함이었다

### 원인을 갈라서 확인했다

같은 획(굵기 13, 가로 300px)을 네 가지 조건으로 그어 봤다 — `zoom-iso.png`.

| 조건 | 결과 |
|---|---|
| 그대로 | 동그란 도장이 꿰인 줄 |
| `jitter`(자리 흔들기) 만 0 | **자국이 그대로 남는다** — 흔들기는 원인이 아니다 |
| `grain`(종이결) 만 0 | **자국이 사라진다** |
| 둘 다 0 | 완전히 매끈한 띠 |

**원인**: 종이결을 dab **하나마다 알파에 곱하고** 있었다. dab 한 장이 통째로 옅어지니
진한 dab 만 동그랗게 드러나고, 옅은 dab 자리가 잘록해진다. 결 세기가 큰 브러시일수록 심했다
(크레용 1.0 · 색연필 0.95 · 소프트 파스텔 0.8).

의도한 재료 질감이 아니다. 종이는 **솟은 결이 색을 다 받고 골만 비는** 것이지
도장이 통째로 옅어지는 것이 아니다.

### 수정

결을 dab 에서 떼어 **획을 다 그은 뒤 픽셀 단위로** 판다.

* dab 은 고르게 찍힌다 → 동그란 자국이 없다
* 결 무늬는 화면 자리에 붙어 있다 → 다시 그려도 입자가 움직이지 않고, 덧칠하면 같은 골에 색이 얹힌다
* 골(무늬값 0.42 아래)만 파고 나머지는 그대로 둔다 → 획이 지지직거리는 잡티가 되지 않는다
* 파이는 가장자리는 부드럽게(smoothstep) → 구멍이 각지지 않는다

**전체를 흐리게 덮지 않았다.** 같은 자리의 잉크량은 오히려 늘었다:

| 브러시 | 수정 전 | 수정 후 | 차이 |
|---|---|---|---|
| 색연필 | 0.542 | 0.586 | +8% |
| 크레용 | 0.570 | 0.620 | +9% |
| 소프트 파스텔 | 0.620 | 0.696 | +12% |
| 연필 옆면 | 0.516 | 0.644 | +25% |
| 오일 파스텔 | 0.541 | 0.546 | +1% |

같은 경로·같은 색·같은 굵기로 잰 것이고, 확대본은 `zoom-beads-v3.png` 다.

**남은 한계**: 소프트 파스텔은 결 칸이 작아(2px) 확대하면 여전히 곱게 깔린 점으로 보인다.

## 3. 과도한 양 끝 테이퍼 — 짧은 획에 일률로 걸려 있었다

### 확인

획 길이를 바꿔 가며 같은 조건으로 그었다 — `zoom-taper.png`(수정 전), `zoom-taper-v4.png`(전후).
캔버스의 8% · 16% · 32% · 84% 와 손글씨 획('ㅡ' · 'ㅣ').

**원인 두 가지**

1. 테이퍼 길이가 **26px 고정**이었다. 손글씨 한 획이 30~70px 이므로 짧은 획은 **전부가 테이퍼** →
   가운데가 없는 나뭇잎 모양이 된다.
2. 끝 굵기의 바닥값이 22% 였다. 획 길이와 무관하게 늘 바늘처럼 가늘어진다.

### 수정 — 브러시 특징은 남기고 일률 적용만 없앴다

| 무엇 | 어떻게 |
|---|---|
| 테이퍼 길이 | `min(설정값, 획 길이 × 0.3)` — 아무리 짧아도 **가운데 40% 는 제 굵기**를 낸다 |
| 끝 굵기 바닥값 | 획이 짧을수록 올린다(획 길이가 설정값의 3배가 되면 원래 값). 붓이 들릴 틈이 없으니까 |
| 테이퍼 펜만 값 조정 | `taper 26→18` · `floor .22→.38` |

긴 획은 여전히 양 끝이 가늘게 빠진다 — 테이퍼 펜의 특징을 없애지 않았다.
**문제가 확인된 둘(테이퍼 펜·붓펜)만** 손봤다.

### 지목되지 않았지만 같이 나온 것

붓펜과 자연 잉크의 **긴 획이 애벌레처럼 울퉁불퉁**했다. 굵기 물결의 마디가 6~12px 이라
획 하나에 여러 번 출렁였다. 마디를 15px 이상으로 늘려 한 획에 한두 번만 출렁이게 했다.
프리셋의 물결 세기 값(`.16` / `.08`)은 건드리지 않았다.
